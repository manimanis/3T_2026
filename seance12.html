Activité 1 : Borne $\le \sqrt{N}$ vs $\le N-1$

Justification Mathématique de la Borne $\lfloor\sqrt{N}\rfloor$

Pourquoi s'arrêter à $\sqrt{N}$ ?

Tout composé $N = a \times b$ ($1 < a \le b < N$) vérifie $a \le \sqrt{N}$ (sinon $a \times b > N$).

👉 Sans diviseur dans $[2, \lfloor\sqrt{N}\rfloor]$, $N$ est **premier** !

Comparaison sur $N = 1\ 000\ 003$

Méthode Naïve ($i \le N - 1$) 1 000 001 étapes

Principe : Teste $i$ de $2$ à $N - 1$.

Itérations pour $N = 1\ 000\ 003$ :
- $i = 2, 3, 4, \dots$
... 999 997 tests inutiles ...
- Fin au test $1\ 000\ 002$ (1 000 001 divisions !)
Inconvénient : 1 000 001 divisions, impraticable au-delà de $10^9$.
Méthode Optimisée ($i \le \lfloor\sqrt{N}\rfloor$) 1 000 étapes

Principe : Teste $i$ jusqu'à $\lfloor\sqrt{1\ 000\ 003}\rfloor = 1000$.

Itérations pour $N = 1\ 000\ 003$ :
- Borne max : $\lfloor\sqrt{N}\rfloor = 1000$
- Test de $i = 2$ à $1000$
- $i > 1000 \implies$ Premier en **1000 tests** !
Gain : $1\ 000\times$ plus rapide.
Comparaison Synthétique
Méthode Borne d'arrêt Itérations ($10^6+3$) Efficacité Norme
Naïve i <= n - 1 1 000 001 Inappropriée ❌ Déconseillée
Optimisée i <= int(sqrt(n)) 1 000 Maximale ✔️ Norme Officielle
Script Python Comparatif des Itérations (À tester dans Python IDE) 
from math import sqrt

# 1. Méthode Naïve (Jusqu'à N-1)
def est_premier_naive(n):
    if n < 2: return False, 0
    count = 0
    for i in range(2, n):
        count += 1
        if n % i == 0:
            return False, count
    return True, count

# 2. Méthode Optimisée (Jusqu'à sqrt(N) sans break)
def est_premier_optimisee(n):
    if n < 2: return False, 0
    i = 2
    test = True
    count = 0
    bound = int(sqrt(n))
    while i <= bound and test:
        count += 1
        if n % i == 0:
            test = False
        else:
            i += 1
    return test, count

# Test du nombre N = 1 000 003
N = 1000003

res1, count1 = est_premier_naive(N)
res2, count2 = est_premier_optimisee(N)

print("--- COMPARAISON DES ITÉRATIONS (N =", N, ") ---")
print("1. Méthode Naïve     : ", count1, "itérations")
print("2. Méthode Optimisée : ", count2, "itérations")
print("Gain d'efficacité    : ", count1 // count2, "fois moins d'itérations !")

Implémentation Python
from math import sqrt

def est_premier(n):
    if n < 2:
        return False
    i = 2
    test = True
    while i <= int(sqrt(n)) and test:
        if n % i == 0:
            test = False
        else:
            i += 1
    return test

def prochain_premier(n):
    p = n + 1
    while not est_premier(p):
        p += 1
    return p

def decomposer_facteurs_premiers(n):
    print("Décomposition en facteurs premiers :")
    div = 2
    temp = n
    while temp > 1:
        while temp % div == 0:
            print(div, end=" ")
            temp = temp // div
        div += 1
    print()

# PROGRAMME PRINCIPAL
n = int(input("Donner N > 1 : "))
while n <= 1:
    n = int(input("Invalide ! N > 1 : "))

print("\n=== BILAN ARITHMÉTIQUE DE", n, "===")
if est_premier(n):
    print(n, "est un NOMBRE PREMIER.")
    suiv = prochain_premier(n)
    print("Prochain nombre premier :", suiv)
else:
    print(n, "est un NOMBRE COMPOSÉ.")
    decomposer_facteurs_premiers(n)

Savoirs (Connaissances)

Règle Ministérielle : Sortie de Boucle sans `break`

En algorithmique et en Python, la sortie anticipée de la boucle Tant Que (dès qu'un diviseur est trouvé) doit impérativement utiliser une variable booléenne test :

Activité 1 : Démonstration d'Efficacité & Preuve Mathématique ($\le \sqrt{N}$ vs $\le N-1$)

1. Justification Mathématique de la Borne $\lfloor\sqrt{N}\rfloor$

Pourquoi est-il inutile de tester les diviseurs au-delà de $\sqrt{N}$ ?

Soit un entier $N > 1$ non premier (un nombre composé). Il s'écrit sous la forme d'un produit de deux entiers $a$ et $b$ tels que : $$N = a \times b \quad \text{avec } 1 < a \le b < N$$

Si les deux facteurs étaient strictement supérieurs à $\sqrt{N}$ ($a > \sqrt{N}$ et $b > \sqrt{N}$), leur produit vérifierait : $$a \times b > \sqrt{N} \times \sqrt{N} = N$$ Ce qui est impossible car $a \times b = N$ !

👉 Conclusion : Tout nombre composé $N$ possède obligatoirement au moins un diviseur $a \le \sqrt{N}$. Si nous n'en trouvons aucun entre $2$ et $\lfloor\sqrt{N}\rfloor$, alors $N$ est obligatoirement **PREMIER** !

2. Analyse Comparative sur le Nombre $N = 1\ 000\ 003$

Méthode Naïve ($i \le N - 1$) 1 000 001 ÉTAPES

Principe : Teste tous les diviseurs possibles de $i = 2$ jusqu'à $N - 1$.

Trace d'exécution pour N = 1 000 003 :
- Test $i = 2$ : $1\ 000\ 003 \pmod 2 \neq 0$
- Test $i = 3$ : $1\ 000\ 003 \pmod 3 \neq 0$
- Test $i = 4$ : $1\ 000\ 003 \pmod 4 \neq 0$
... [ 999 997 itérations inutiles ] ...
- Test $i = 1\ 000\ 002$ : Boucle terminée (1 000 001 tests !)
Inconvénient : Exécute 1 000 001 divisions. Extrêmement lent si $N$ dépasse $10^9$.
Méthode Optimisée ($i \le \lfloor\sqrt{N}\rfloor$) 1 000 ÉTAPES

Principe : Teste la divisibilité de $i = 2$ uniquement jusqu'à $\lfloor\sqrt{1\ 000\ 003}\rfloor = 1000$.

Trace d'exécution pour N = 1 000 003 :
- Borne max calculée : $\lfloor\sqrt{1\ 000\ 003}\rfloor = 1000$
- Test $i = 2, 3, 4, \dots$ jusqu'à $i = 1000$
- $i > 1000 \implies$ Fin de la boucle ! 1000 tests seulement !
.
Gain Spectaculaire : Algorithme 1 000 fois plus rapide (1 000 tests au lieu de 1 000 001).

from math import sqrt

# 1. Méthode Naïve (Jusqu'à N-1)
def est_premier_naive(n):
    if n < 2: return False, 0
    count = 0
    for i in range(2, n):
        count += 1
        if n % i == 0:
            return False, count
    return True, count

# 2. Méthode Optimisée (Jusqu'à sqrt(N) sans break)
def est_premier_optimisee(n):
    if n < 2: return False, 0
    i = 2
    test = True
    count = 0
    bound = int(sqrt(n))
    while i <= bound and test:
        count += 1
        if n % i == 0:
            test = False
        else:
            i += 1
    return test, count

# Test du nombre N = 1 000 003
N = 1000003

res1, count1 = est_premier_naive(N)
res2, count2 = est_premier_optimisee(N)

print("--- COMPARAISON DES ITÉRATIONS (N =", N, ") ---")
print("1. Méthode Naïve     : ", count1, "itérations")
print("2. Méthode Optimisée : ", count2, "itérations")
print("Gain d'efficacité    : ", count1 // count2, "fois moins d'itérations !")

Implémentation Python Officielle (Python IDE)
from math import sqrt

def est_premier(n):
    if n < 2:
        return False
    i = 2
    test = True
    while i <= int(sqrt(n)) and test:
        if n % i == 0:
            test = False
        else:
            i += 1
    return test

def prochain_premier(n):
    p = n + 1
    while not est_premier(p):
        p += 1
    return p

def decomposer_facteurs_premiers(n):
    print("Décomposition en facteurs premiers :")
    div = 2
    temp = n
    while temp > 1:
        while temp % div == 0:
            print(div, end=" ")
            temp = temp // div
        div += 1
    print()

# PROGRAMME PRINCIPAL
n = int(input("Donner N > 1 : "))
while n <= 1:
    n = int(input("Invalide ! N > 1 : "))

print("\n=== BILAN ARITHMÉTIQUE DE", n, "===")
if est_premier(n):
    print(n, "est un NOMBRE PREMIER.")
    suiv = prochain_premier(n)
    print("Prochain nombre premier :", suiv)
else:
    print(n, "est un NOMBRE COMPOSÉ.")
    decomposer_facteurs_premiers(n)

Algorithmique & Python — 3e Sciences expérimentales

PHASE 0 — Cadre de travail

Périmètre : Prérequis de 2e année dans le domaine « Pensée computationnelle et programmation ». La robotique, l'ESP32 et les objets connectés sont explicitement exclus de cette série.

Objectifs de la série

  • Réactiver les acquis de 2e sans introduire les nouvelles notions de 3e.
  • Observer la manière dont l'élève lit, simule, corrige, modifie et construit une solution.
  • Évaluer la continuité entre algorithme et Python ainsi que la capacité à tester une solution.
  • Dégager un profil de besoins pour organiser les premières remédiations de l'année.

Consignes générales

  • Phase A : travailler sans exécuter de programme (mobilisation « à froid »).
  • Phase B : utiliser le rappel express fourni, puis corriger ou compléter.
  • Phase C : travailler sans rappel détaillé et justifier les choix importants.
  • Règle : quand un résultat est demandé, écrire l'attendu avant toute exécution.
Important : Cette série est diagnostique : une erreur n'est pas seulement « un point perdu », elle aide à repérer ce qui doit être réactivé. Le barème /40 est indicatif et ne remplace pas l'analyse par compétences. Rédigez toutes vos réponses sur votre cahier.

PHASE B — Réactivation active

Un rappel express est maintenant autorisé · compléter, corriger et modifier · 4 exercices · 40 min

Rappel express — conventions utilisées dans cette série

  • Algorithmique : Objet ← Expression ; Si Condition Alors … [Sinon …] FinSi ; Pour i de Début à Fin Faire … Fin Pour.
  • Python : objet = expression ; if condition: … else: … ; for i in range(Début, Fin+1): ….
  • Entrée Python : input() retourne une chaîne ; utiliser int(input()) ou float(input()) lorsque la donnée est numérique.

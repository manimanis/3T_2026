III. Conversions de Types en Python

Puisque input() renvoie systématiquement une chaîne de caractères (str), une conversion explicite est indispensable avant tout calcul numérique :

Exemples de conversions explicites 
# Conversion d'une chaîne vers un entier
nb = int(input("Donner un nombre entier : "))

# Conversion d'une chaîne vers un réel
prix = float(input("Donner le prix : "))

# Conversion d'un nombre vers une chaîne (pour concaténation)
message = "Votre note est : " + str(15.5)

Activités Pratiques

Activité 1 : Analyse et correction de séquence code

Activité 1 : Analyse et Correction de Séquence Code (10 min)

Exercice Diagnostique

Analyse le script Python ci-dessous. Pourquoi ce code produit-il un résultat inattendu ?

Séquence erronée :
a = input("Donner a : ")
b = input("Donner b : ")
somme = a + b
print("La somme est :", somme)
Analyse & Solution :

Analyse de l'erreur : Si l'utilisateur saisit 5 pour a et 3 pour b, la variable somme vaudra "53" (concaténation de chaînes) au lieu de 8 !

Séquence corrigée
a = int(input("Donner a : "))
b = int(input("Donner b : "))
somme = a + b
print("La somme est :", somme)

Activité 2 : Mini-projet calcul de pénalité de retard

Activité 2 : Mini-Projet Calcul de Pénalité de Retard (25 min)

Énoncé du Problème :

On souhaite concevoir une application pour une bibliothèque scolaire qui calcule le montant total de pénalité de retard pour l'emprunt d'un livre.

  • Le système demande le nom de l'élève, le titre du livre et le nombre de jours de retard.
  • La pénalité de base est fixée à 0.500 DT par jour de retard.
  • Une taxe fixe de gestion de 1.200 DT est ajoutée au montant total.
Formule mathématique : $$ \text{montant\_total} = (\text{nb\_jours} \times 0.500) + 1.200 $$

  • Entrées : Nom de l'élève (nom : Chaîne), Titre du livre (titre : Chaîne), Jours de retard (nb_jours : Entier).
  • Sortie : Montant total à payer (montant_total : Réel).
  • Traitement : montant_total = (nb_jours * 0.500) + 1.200.

Objet Type / Nature Rôle
nom Chaîne de caractères Nom de l'élève
titre Chaîne de caractères Titre du livre
nb_jours Entier Jours de retard
montant_total Réel Montant total final
TARIF_JOUR Constante = 0.500 Tarif journalier
TAXE_FIXE Constante = 1.200 Frais de gestion 

ALGORITHME Calcul_Penalite
DEBUT
    Écrire("Nom de l'élève : ")
    Lire(nom)
    Écrire("Titre du livre : ")
    Lire(titre)
    Écrire("Nombre de jours de retard : ")
    Lire(nb_jours)
    
    montant_total ← (nb_jours * 0.500) + 1.200
    
    Écrire("Élève : ", nom)
    Écrire("Livre : ", titre)
    Écrire("Montant total de la pénalité : ", montant_total, " DT")
FIN

script_penalite.py 
# Declarations des constantes
TARIF_JOUR = 0.500
TAXE_FIXE = 1.200

# Saisie des donnees
nom = input("Nom de l'élève : ")
titre = input("Titre du livre : ")
nb_jours = int(input("Nombre de jours de retard : "))

# Traitement
montant_total = (nb_jours * TARIF_JOUR) + TAXE_FIXE

# Affichage des resultats
print("\n--- FICHE DE PÉNALITÉ ---")
print("Élève :", nom)
print("Livre :", titre)
print("Montant total à payer :", montant_total, "DT")

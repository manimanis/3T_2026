Synthèse du Cours

2. Concept & Déclaration des Tableaux à 1 Dimension

Un tableau à 1 dimension est une suite de cases mémoire contiguës, identifiées par un même nom d'objet et accessibles individuellement grâce à un **indice** scalaire.

Diagramme Mémoire Vectoriel : Représentation d'un Tableau 1D
Correspondance des Déclarations Algorithme vs Python (numpy)
Type des Élément Déclaration Algorithmique (TDO) Déclaration Python (from numpy import array)
Entiers T : Tableau de N Entier T = array([0] * N)
Réels T : Tableau de N Réel T = array([float()] * N) ou T = array([0.0] * N)
Chaînes de car. T : Tableau de N Chaîne T = array([''] * N, dtype='U20')
Booléens T : Tableau de N Booléen T = array([False] * N)
Les 3 Étapes Systématiques de Manipulation d'un Tableau 1D
1. Contrôle de la taille $N$
n = int(input("N (3 à 30) : "))
while not (3 <= n <= 30):
    n = int(input("Invalide ! : "))
2. Saisie (Remplissage)
# Indices de 0 à n-1
for i in range(n):
    T[i] = float(input(...))
3. Affichage Élement par Élement
print("Contenu :")
for i in range(n):
    print("T[", i, "] =", T[i])
Exigences Ministérielles Importantes (Baccalauréat 2024-2025)
  1. Importation obligatoire de numpy : En Tunisie, les tableaux doivent obligatoirement être déclarés à l'aide de from numpy import array.
  2. Indices de $0$ à $N-1$ : Le premier élément est toujours localisé à l'indice 0 et le dernier à l'indice N - 1.
  3. 🚫 Interdiction d'affichage global : L'instruction print(T) est strictement interdite. L'affichage doit toujours s'effectuer élément par élément dans une boucle.

Activité 1 : Détection & Correction d'Erreurs Fréquentes

Correction d'un Code Non Conforme

Identifions les 3 erreurs classiques d'un élève (listes standard, indices de 1 à N et `print(T)`) et réécrivons le script conforme aux normes officielles.

Code Invalide (3 Erreurs Majeures) 
# ❌ 3 Erreurs classiques à éviter !
T = [0] * 10            # Erreur 1: Liste standard au lieu de numpy
n = int(input("N : "))

for i in range(1, n + 1): # Erreur 2: Indices 1 à n (IndexError !)
    T[i] = input("Val : ")

print(T)                # Erreur 3: Affichage direct interdit !
  • Erreur 1 : Utilisation d'une liste Python standard au lieu de numpy.array.
  • Erreur 2 : La boucle tente d'accéder à T[n] (hors limites !).
  • Erreur 3 : L'instruction print(T) viole la règle d'affichage ministérielle.
Code Corrigé & Conforme 
from numpy import array

n = int(input("Taille (1 à 10) : "))
while not (1 <= n <= 10):
    n = int(input("Taille invalide (1 à 10) : "))

# ✅ 1. Déclaration numpy obligatoire
T = array([0] * n)

# ✅ 2. Indices exacts de 0 à n - 1
for i in range(n):
    T[i] = int(input("Donner T[" + str(i) + "] : "))

# ✅ 3. Affichage élément par élément
print("\nContenu du tableau :")
for i in range(n):
    print("Élément N°", i, ":", T[i])

Implémentation Python (Python IDE)
from numpy import array

# 1. Saisie et controle de N
n = int(input("Donner N (3 à 31) : "))
while not (3 <= n <= 31):
    n = int(input("Invalide ! Saisir N (3 à 31) : "))

# 2. Declaration du tableau numpy de N réels
Temp = array([0.0] * n)

# 3. Remplissage du tableau
for i in range(n):
    Temp[i] = float(input("Jour " + str(i + 1) + " : "))

# 4. Affichage element par element (Obligatoire)
print("\n=== BULLETIN MÉTÉO RÉCAPITULATIF ===")
for i in range(n):
    print("Jour", i + 1, ":", Temp[i], "°C")

Savoirs
  • Principe de la **recherche séquentielle** : parcours indicé de $0$ à $N-1$.

Interdiction de l'instruction `break`

L'instruction break est strictement interdite. Utiliser la condition composée :
while i < n and not trouve:.

Activité 1 : Transformation de Code Non Conforme (Sans `break`)

Correction d'un Script avec Boucle `for` et `break`

Code Non Conforme (Interdit au Bac)

Utilise for et break pour interrompre la recherche. 

# NON CONFORME (Interdit)
def chercher_mauvais(T, n, val):
    pos = -1
    for i in range(n):
        if T[i] == val:
            pos = i
            break  # INTERDIT !
    return pos
Code Conforme (Norme Officielle)

Utilise while et un indicateur booléen trouve. 

# CONFORME AUX DIRECTIVES
def chercher_conforme(T, n, val):
    i = 0
    trouve = False
    pos = -1
    while i < n and not trouve:
        if T[i] == val:
            trouve = True
            pos = i
        else:
            i += 1
    return pos

Implémentation Python Officielle (Python IDE)
from numpy import array

def recherche_sequentielle(T, n, val):
    i = 0
    trouve = False
    pos = -1
    while i < n and not trouve:
        if T[i] == val:
            trouve = True
            pos = i
        else:
            i += 1
    return pos

def saisir_donnees(IDs, Moyennes, n):
    for i in range(n):
        id_saisi = int(input("ID élève N° " + str(i+1) + " : "))
        while id_saisi <= 0 or recherche_sequentielle(IDs, i, id_saisi) != -1:
            id_saisi = int(input("ID invalide ou existant ! ID unique > 0 : "))
        IDs[i] = id_saisi
        
        moy = float(input("Moyenne (0 à 20) : "))
        while not (0.0 <= moy <= 20.0):
            moy = float(input("Invalide ! Note 0 à 20 : "))
        Moyennes[i] = moy

# PROGRAMME PRINCIPAL
n = int(input("Nombre d'élèves (3 à 25) : "))
IDs = array([0] * n)
Moyennes = array([float()] * n)

saisir_donnees(IDs, Moyennes, n)

id_c = int(input("ID à chercher : "))
idx = recherche_sequentielle(IDs, n, id_c)

if idx != -1:
    print("Trouvé ! ID:", IDs[idx], "Moyenne:", Moyennes[idx], "/ 20")
else:
    print("Élève non répertorié")

Évaluation Formative

Quiz Interactif

1. Principe de la recherche séquentielle ?
  • Examiner chaque élément du début à la fin
  • Diviser le tableau en deux
  • Trier d'abord le tableau
  • Vérifier uniquement le premier et dernier
2. Comparaisons max dans un tableau non trié de N éléments ?
  • 1 comparaison
  • N comparaisons
  • log2(N) comparaisons
  • N / 2 comparaisons
3. Valeur retournée si l'élément est introuvable ?
  • 0
  • N
  • -1 (ou False)
  • 999
4. Condition d'arrêt de la recherche ?
  • (Trouve == Vrai) OU (i >= N)
  • i == N
  • Trouve == Faux
  • i == 0
5. Le tableau doit-il être trié ?
  • Non, fonctionne sur tout tableau (trié ou non)
  • Oui, trié croissant obligatoirement
  • Oui, trié décroissant obligatoirement
  • Uniquement si N > 100

Activité 1 — Contrôle d'accès sécurisé à une machine-outil (MOCN)

4 points
Mise en situation technique & Cahier des charges

Sur une machine-outil à commande numérique (MOCN), l'accès au pupitre de commande est verrouillé. Pour s'authentifier, l'opérateur doit introduire un code numérique strictement positif ($code \in \mathbb{N}^*$).

Le module de sécurité exécute un traitement séquentiel en trois étapes indissociables :

  1. Étape 1 — Saisie filtrée obligatoire : Le système invite l'utilisateur à saisir code. Tant que la valeur entrée est invalide ($code \le 0$), le système affiche « Code invalide ! Entrez un entier strictement positif. » et réitère la demande.
  2. Étape 2 — Analyse du format & Décompte des chiffres (Ex. 5) : Une fois le code validé, le système détermine son nombre exact de chiffres par divisions entières successives par 10 (copie_code // 10), sans jamais recourir à la conversion en chaîne de caractères (interdiction formelle de str() ou len()).
  3. Étape 3 — Décision d'habilitation :
    • Si le code comporte 4 chiffres $\implies$ Afficher « Accès Technicien Régleur autorisé ».
    • Si le code comporte 3 chiffres $\implies$ Afficher « Accès Opérateur Usinage autorisé ».
    • Pour tout autre format $\implies$ Afficher « Format de code non accrédité : Accès refusé ! ».
Rédigez l'algorithme complet sur votre feuille et enregistrez le script sous TP1_Nom_Prenom.py.
Principe algorithmique & Validation
Trace des divisions (Exemple : code = 5403)
// Initialisation : copie_code ← code (5403), nb ← 0
// Étape 1 : 5403 div 10 = 540  -> nb = 1
// Étape 2 :  540 div 10 =  54  -> nb = 2
// Étape 3 :   54 div 10 =   5  -> nb = 3
// Étape 4 :    5 div 10 =   0  -> nb = 4
// Arrêt : copie_code = 0  -> Résultat = 4 chiffres
// Habilitation : Profil « Technicien Régleur »

Jeux d'essais obligatoires :

  • $code = 5403 \implies \mathbf{4}$ chiffres $\implies$ Technicien Régleur
  • $code = 176 \implies \mathbf{3}$ chiffres $\implies$ Opérateur Usinage
  • $code = 9 \implies \mathbf{1}$ chiffre $\implies$ Format non accrédité
  • $code = -45 \implies$ Erreur et répétition de saisie

4 points

Mise en situation industrielle : Sur une chaîne automatisée de contrôle qualité, un capteur de télémétrie laser optique mesure en temps réel la distance séparant l'émetteur d'une série de pièces usinées défilant sur un convoyeur.

Chaque mesure valide correspond à une distance réelle positive $A \ge 0.0\text{ cm}$. La transmission de données s'arrête dès que le capteur émet la valeur sentinelle `-1.0` (détection de fin de lot ou arrêt du défilement).

Le programme ne connaît pas à l'avance le nombre d'échantillons qui seront transmis au cours de la mesure.

Activité 5 — Modélisation dynamique comparée : Lignes de fabrication Exercice 20 du Recueil

Excellence · 2 points

Mise en situation industrielle (Usine automatisée) : Deux lignes de fabrication robotisées produisent des composants électroniques :
• Ligne $\alpha$ (Croissance linéaire) : Production initiale $P_\alpha = 10\,000\,000$ pièces, avec une cadence constante de $+500\,000\text{ pièces/h}$.
• Ligne $\beta$ (Croissance géométrique) : Production initiale $P_\beta = 5\,000\,000$ pièces, optimisée avec un gain continu de $+3\%$ par heure ($P_\beta \leftarrow P_\beta \times 1.03$).
Objectif : Déterminer au bout de combien d'heures de fonctionnement la production de la ligne $\beta$ dépassera celle de la ligne $\alpha$.

Jalons d'évolution horaire :

Temps $t$ Ligne $\alpha$ (Linéaire) Ligne $\beta$ (Exponentielle) $P_\beta > P_\alpha$ ?
$t = 0\text{ h}$ $10.0\text{ M}$ $5.00\text{ M}$ Non
$t = 20\text{ h}$ $20.0\text{ M}$ $9.03\text{ M}$ Non
$t = 40\text{ h}$ $30.0\text{ M}$ $16.31\text{ M}$ Non
$t = 60\text{ h}$ $40.0\text{ M}$ $29.46\text{ M}$ Non
$t = 77\text{ h}$ 48.50 M 48.69 M OUI (Dépassement !)

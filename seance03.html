Synthèse du Cours

2. Structure Selon / match...case

Sélectionne un traitement selon la valeur d'une variable unique (sélecteur).

Le sélecteur doit être de type scalaire (Entier, Caractère, Booléen). Réel et Chaîne sont exclus.

Diagramme d'exécution vectoriel : Structure Selon / match...case
Algorithme 
Selon Sélecteur
    Valeur1 : Traitement1
    Valeur2, Valeur3 : Traitement2
    Valeur4 .. Valeur5 : Traitement3
    Sinon
        TraitementParDéfaut
Fin Selon
Python 3.10+ (match ... case) 
match selecteur:
    case valeur1:
        traitement1
    case valeur2 | valeur3:
        traitement2
    case s if valeur4 <= s <= valeur5:
        traitement3
    case _:
        traitement_par_defaut
Exemple Concret : Détermination de Mention selon la Note
Algorithme : 
Selon note
    0 .. 9 : mention ← "Ajourné"
    10 .. 11 : mention ← "Passable"
    12 .. 13 : mention ← "Assez Bien"
    14 .. 15 : mention ← "Bien"
    16 .. 20 : mention ← "Très Bien"
    Sinon : mention ← "Note invalide"
Fin Selon
Python 3.10+ (match ... case) : 
match note:
    case n if 0 <= n <= 9:
        mention = "Ajourné"
    case n if 10 <= n <= 11:
        mention = "Passable"
    case n if 12 <= n <= 13:
        mention = "Assez Bien"
    case n if 14 <= n <= 15:
        mention = "Bien"
    case n if 16 <= n <= 20:
        mention = "Très Bien"
    case _:
        mention = "Note invalide"
Correspondance des Notations Algorithmiques et Python
Cas de figure Syntaxe Algorithmique Syntaxe Python (match...case) Exemple concret
Valeur isolée 1 : Traitement case 1: Option 1 de menu
Liste de valeurs 'A', 'E', 'I', 'O' : Traitement case 'A' | 'E' | 'I' | 'O': Test des voyelles
Intervalle de valeurs 10 .. 20 : Traitement case x if 10 <= x <= 20: Note suffisante entre 10 et 20
Option par défaut Sinon : Traitement case _: Saisie incorrecte ou hors limites

Activité 1 : Analyse Comparée & Refactoring (if...elif → match...case)

Activité 1 : Refactoring if/elif → match/case (10 min)

Comparez les deux versions (if...elif vs match...case) et répondez aux questions :

Version 1 : Code initial (avec if / elif) 
code = int(input("Entrez le code tarifaire (1-4) : "))

if code == 1:
    tarif = 10.0
elif code == 2 or code == 3:
    tarif = 15.0
elif code == 4:
    tarif = 20.0
else:
    tarif = 0.0
    print("Code invalide")

print("Tarif appliqué :", tarif, "DT")
Version 2 : Code modernisé (avec match...case) 
code = int(input("Entrez le code tarifaire (1-4) : "))

match code:
    case 1:
        tarif = 10.0
    case 2 | 3:
        tarif = 15.0
    case 4:
        tarif = 20.0
    case _:
        tarif = 0.0
        print("Code invalide")

print("Tarif appliqué :", tarif, "DT")
Questions d'Analyse et de Réflexion
  1. Identification du Sélecteur : Quelle est la variable testée dans la structure match et quel est son type ?
  2. Traduction de la liste de valeurs : Comment l'instruction alternative elif code == 2 or code == 3: a-t-elle été simplifiée dans le bloc match...case ?
  3. Traitement par défaut : À quoi correspond le motif case _: et quel est son rôle ?
  4. Avantage de lisibilité : Pourquoi la structure match...case est-elle préférée à une longue suite de if...elif lorsque l'on teste les valeurs d'une seule variable ?

Activité 2 : Convertisseur de Stockage & Calculateur Réseau

Activité 2 : Convertisseur de Stockage & Réseau

Énoncé :

Convertir des tailles de stockage (Octets) et calculer la durée de téléchargement (10 Mo/s) :

  • Option 1 : Octets → Ko ($1 \text{ Ko} = 1024 \text{ Octets}$).
  • Option 2 : Octets → Mo ($1 \text{ Mo} = 1024^2 \text{ Octets}$).
  • Option 3 : Octets → Go ($1 \text{ Go} = 1024^3 \text{ Octets}$).
  • Option 4 : Durée de téléchargement (vitesse fixe 10 Mo/s).

Implémentation Python 3.10+ (Python IDE)
# Constantes
VITESSE_MO_S = 10.0

choix = int(input("Votre choix (1-4) : "))
taille_octets = float(input("Donner la taille en Octets : "))

match choix:
    case 1:
        resultat = taille_octets / 1024
        print("Taille en Ko :", round(resultat, 3))
    case 2:
        resultat = taille_octets / (1024 * 1024)
        print("Taille en Mo :", round(resultat, 3))
    case 3:
        resultat = taille_octets / (1024 * 1024 * 1024)
        print("Taille en Go :", round(resultat, 4))
    case 4:
        taille_mo = taille_octets / (1024 * 1024)
        resultat = taille_mo / VITESSE_MO_S
        print("Durée estimée :", round(resultat, 2), "s")
    case _:
        print("Erreur : Choix invalide !")

Synthèse du Cours

2. La Structure Conditionnelle à Choix Multiples (Selon / match...case)

La structure à choix multiples permet de sélectionner un traitement parmi plusieurs en fonction de la valeur d'une seule expression appelée Sélecteur.

Règle fondamentale sur le Sélecteur

Le sélecteur doit être impérativement de type scalaire (Entier ou Caractère). Les types Réel et Chaîne de caractères doivent être évités comme sélecteur en algorithmique officielle ministérielle.

Diagramme d'exécution vectoriel : Structure Selon / match...case
Algorithme 
Selon Sélecteur
    Valeur1 : Traitement1
    Valeur2, Valeur3 : Traitement2
    Valeur4 .. Valeur5 : Traitement3
    Sinon
        TraitementParDéfaut
Fin Selon
Python 3.10+ (match ... case) 
match selecteur:
    case valeur1:
        traitement1
    case valeur2 | valeur3:
        traitement2
    case s if valeur4 <= s <= valeur5:
        traitement3
    case _:
        traitement_par_defaut
Correspondance des Notations Algorithmiques et Python
Cas de figure Syntaxe Algorithmique Syntaxe Python (match...case) Exemple concret
Valeur isolée 1 : Traitement case 1: Option 1 de menu
Liste de valeurs 'A', 'E', 'I', 'O' : Traitement case 'A' | 'E' | 'I' | 'O': Test des voyelles
Intervalle de valeurs 10 .. 20 : Traitement case x if 10 <= x <= 20: Note suffisante entre 10 et 20
Option par défaut Sinon : Traitement case _: Saisie incorrecte ou hors limites

Activité 1 : Refactoring de Code (if...elif → match...case)

Analyse & Modernisation de Code

Comparaison entre l'ancienne syntaxe à blocs if...elif et la structure moderne match...case de Python 3.10.

Code initial (Lourd avec if / elif) 
code = int(input("Entrez le code tarifaire (1-4) : "))

if code == 1:
    tarif = 10.0
elif code == 2 or code == 3:
    tarif = 15.0
elif code == 4:
    tarif = 20.0
else:
    tarif = 0.0
    print("Code invalide")
Code modernisé avec match...case 
code = int(input("Entrez le code tarifaire (1-4) : "))

match code:
    case 1:
        tarif = 10.0
    case 2 | 3:
        tarif = 15.0
    case 4:
        tarif = 20.0
    case _:
        tarif = 0.0
        print("Code invalide")

print("Tarif appliqué :", tarif, "DT")

Activité 2 : Convertisseur de Stockage & Calculateur Réseau

Problème Pratique complet

Énoncé du problème :

On souhaite concevoir une application interactive pour convertir des tailles de stockage mémoire (en Octets) et calculer la durée estimée de téléchargement réseau.

  • Option 1 : Convertir des Octets en Kilo-Octets (Ko) ($1 \text{ Ko} = 1024 \text{ Octets}$).
  • Option 2 : Convertir des Octets en Méga-Octets (Mo) ($1 \text{ Mo} = 1024 \times 1024 \text{ Octets}$).
  • Option 3 : Convertir des Octets en Giga-Octets (Go) ($1 \text{ Go} = 1024^3 \text{ Octets}$).
  • Option 4 : Calculer la durée de téléchargement en secondes sur une ligne de 10 Mo/s.

Implémentation Python 3.10+ (Thonny IDE)
# Constantes
VITESSE_MO_S = 10.0

choix = int(input("Votre choix (1-4) : "))
taille_octets = float(input("Donner la taille en Octets : "))

match choix:
    case 1:
        resultat = taille_octets / 1024
        print("Taille en Ko :", round(resultat, 3))
    case 2:
        resultat = taille_octets / (1024 * 1024)
        print("Taille en Mo :", round(resultat, 3))
    case 3:
        resultat = taille_octets / (1024 * 1024 * 1024)
        print("Taille en Go :", round(resultat, 4))
    case 4:
        taille_mo = taille_octets / (1024 * 1024)
        resultat = taille_mo / VITESSE_MO_S
        print("Durée estimée :", round(resultat, 2), "s")
    case _:
        print("Erreur : Choix invalide !")

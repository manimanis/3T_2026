Capteurs Analogiques vs Numériques & ADC 12 bits

1. Différence Fondamentale entre Capteurs

Capteurs Analogiques (ex: LDR)

Délivrent une **tension électrique continue** comprise entre $0.0\,\text{V}$ et $3.3\,\text{V}$ proportionnelle à la grandeur physique mesurée.

Luminosité ➔ Tension $V_{\text{in}} \in [0.0\text{V}, 3.3\text{V}]$ ➔ Broche ADC ESP32
Capteurs Numériques (ex: DHT11)

Délivrent directement une **trame de bits numériques** (série de 0 et 1) codant les grandeurs physiques (Température, Humidité).

Temp & Humidité ➔ Trame de bits ➔ Broche GPIO numérique

2. Le Convertisseur Analogique-Numérique (ADC 12 bits) de l'ESP32

L'ESP32 intègre un **CAN / ADC de 12 bits**. Il convertit la tension d'entrée analogique $V_{\text{in}}$ (entre $0\,\text{V}$ et $3.3\,\text{V}$) en une valeur entière brute $N_{\text{ADC}}$ variant de **0 à 4095** ($2^{12} = 4096$ valeurs).

Formule de Conversion de Tension : $$V_{\text{in}} = \frac{N_{\text{ADC}}}{4095} \times 3.3\,\text{V}$$
Valeur Brute $N_{\text{ADC}}$ Calcul Tension $V_{\text{in}}$ Tension Mesurée Niveau de Luminosité LDR
0 (0 / 4095) × 3.3 V 0.00 V Obscurité totale
1024 (1024 / 4095) × 3.3 V 0.83 V Faible luminosité
2048 (2048 / 4095) × 3.3 V 1.65 V Lumière ambiante moyenne
3072 (3072 / 4095) × 3.3 V 2.48 V Lumière forte
4095 (4095 / 4095) × 3.3 V 3.30 V Plein soleil / Saturation

Scripts d'Acquisition MicroPython & C++

1. Acquisition Analogique LDR (MicroPython)

La photorésistance LDR est branchée en pont diviseur de tension sur le GPIO 34 :

from machine import ADC, Pin
import time

# Initialisation du CAN sur le GPIO 34 (ADC1_CH6)
ldr = ADC(Pin(34))
# Configuration de l'atténuation 11dB (lecture jusqu'à 3.3V)
ldr.atten(ADC.ATTN_11DB)

while True:
    val_brute = ldr.read()  # Entier de 0 à 4095
    tension = (val_brute / 4095.0) * 3.3
    print("Valeur ADC :", val_brute, "| Tension :", round(tension, 2), "V")
    time.sleep(1)

2. Acquisition Numérique DHT11 (MicroPython)

Le capteur DHT11 mesure la Température (°C) et l'Humidité (%) sur le GPIO 15 :

import dht
from machine import Pin
import time

# Initialisation du capteur sur le GPIO 15
capteur = dht.DHT11(Pin(15))

while True:
    try:
        capteur.measure()
        t = capteur.temperature()
        h = capteur.humidity()
        print("Température :", t, "°C | Humidité :", h, "%")
    except OSError:
        print("Erreur de lecture du capteur")
    time.sleep(2)

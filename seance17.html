Capteurs & Convertisseur ADC 12 bits

Signaux Analogiques vs Numériques

Capteurs Analogiques (ex: LDR)

Délivrent une tension continue $V_{\text{in}} \in [0.0\,\text{V}, 3.3\,\text{V}]$ proportionnelle à la grandeur physique.

Luminosité → Tension $[0\,\text{V}, 3.3\,\text{V}]$ → Broche ADC
Capteurs Numériques (ex: DHT11)

Transmettent directement une trame binaire codant les mesures (Température, Humidité).

Temp & Humidité → Trame binaire → Broche GPIO

Convertisseur ADC 12 bits

L'ADC convertit la tension analogique $V_{\text{in}} \in [0, 3.3\,\text{V}]$ en un entier $N_{\text{ADC}} \in [0, 4095]$ ($2^{12} = 4096$ niveaux) :

Formule de Conversion : $$V_{\text{in}} = \frac{N_{\text{ADC}}}{4095} \times 3.3\,\text{V}$$
$N_{\text{ADC}}$ Calcul Tension $V_{\text{in}}$ État LDR
0 (0 / 4095) × 3.3 V 0.00 V Obscurité totale
1024 (1024 / 4095) × 3.3 V 0.83 V Faible luminosité
2048 (2048 / 4095) × 3.3 V 1.65 V Lumière moyenne
3072 (3072 / 4095) × 3.3 V 2.48 V Lumière forte
4095 (4095 / 4095) × 3.3 V 3.30 V Plein soleil

Scripts d'Acquisition MicroPython

LDR (Pont Diviseur — GPIO 34)

from machine import ADC, Pin
import time

ldr = ADC(Pin(34))
ldr.atten(ADC.ATTN_11DB)  # Échelle 0-3.3V

while True:
    val_brute = ldr.read()  # 0 à 4095
    tension = (val_brute / 4095.0) * 3.3
    print("ADC :", val_brute, "| Tension :", round(tension, 2), "V")
    time.sleep(1)

DHT11 (Température & Humidité — GPIO 15)

import dht
from machine import Pin
import time

capteur = dht.DHT11(Pin(15))

while True:
    try:
        capteur.measure()
        t = capteur.temperature()
        h = capteur.humidity()
        print("T :", t, "°C | H :", h, "%")
    except OSError:
        print("Erreur capteur")
    time.sleep(2)

QCM d'Auto-évaluation

1. Plage de sortie de l'ADC 12 bits de l'ESP32 :
  • 0 à 4095 (4096 niveaux)
  • 0 à 1023 (10 bits)
  • 0 à 255 (8 bits)
  • 0.0 à 100.0
2. Capteur utilisé pour mesurer la luminosité :
  • DHT11
  • Photorésistance LDR
  • Servomoteur SG90
  • Buzzer
3. Grandeurs physiques mesurées par le DHT11 :
  • Lumière et son
  • Tension et courant
  • Température et humidité relative
  • Pression et altitude
4. Configuration de la lecture ADC sur le GPIO 34 :
  • adc = ADC(Pin(34))
  • adc = ReadAnalog(34)
  • adc = Pin(34, Pin.ADC)
  • adc = Sensor(34)
5. Nature d'un signal électrique variant de façon continue :
  • Signal analogique
  • Signal binaire
  • Signal Tout-ou-Rien
  • Signal PWM

2. Algorithme d'Euclide & PGCD / PPCM

L'algorithme d'Euclide remplace $(a, b)$ par $(b, a \pmod b)$ jusqu'à ce que $b = 0$ ; le PGCD est alors $a$.

Diagramme Vectoriel : Algorithme d'Euclide & Formule du PPCM
Exemple Pratique de Traçage : PGCD(48, 18)
Étape Variable a Variable b Reste r = a Mod b Action / Mise à jour
1 48 18 12 a ← 18, b ← 12
2 18 12 6 a ← 12, b ← 6
3 12 6 0 b = 0 $\to$ Boucle terminée ! PGCD = 6

Activité 1 : Soustractions vs Euclide

Complexité pour $a = 1\ 000\ 000$ et $b = 2$

Comparaison d'exécution entre soustractions successives et divisions d'Euclide.

Soustractions Successives 500 000 étapes

Principe : $a \leftarrow a - b$ tant que $a \neq b$.

Itérations :
- Étape 1 : $1\ 000\ 000 - 2 = 999\ 998$
... 499 998 itérations ...
- Étape 500 000 : $a = b = 2 \implies \text{PGCD} = 2$
Inconvénient : 500 000 soustractions, inefficace pour les grands nombres.
Divisions d'Euclide 1 seule étape

Principe : $(a, b) \leftarrow (b, a \pmod b)$ tant que $b \neq 0$.

Itérations :
- Étape 1 : $1\ 000\ 000 \pmod 2 = 0$ ($r = 0$)
- $a \leftarrow 2, b \leftarrow 0$
- $b = 0 \implies \text{PGCD} = 2$
Avantage : 1 seule division, complexité logarithmique.
Comparaison Synthétique
Méthode Opération Itérations ($10^6, 2$) Efficacité Norme
Soustractions a ← a - b 500 000 Inappropriée ❌ Déconseillée
Euclide r ← a Mod b 1 Maximale ✔️ Norme Officielle
Code Python Comparatif
# 1. Méthode par Soustractions (Lente)
def pgcd_soustractions(a, b):
    count = 0
    while a != b:
        if a > b:
            a = a - b
        else:
            b = b - a
        count += 1
    return a, count

# 2. Méthode d'Euclide (Rapide)
def pgcd_euclide(a, b):
    count = 0
    while b != 0:
        r = a % b
        a = b
        b = r
        count += 1
    return a, count

# Test comparatif
a, b = 1000000, 2
res1, it1 = pgcd_soustractions(a, b)
res2, it2 = pgcd_euclide(a, b)

print("Soustractions : PGCD =", res1, "en", it1, "itérations")
print("Euclide       : PGCD =", res2, "en", it2, "itération")

Implémentation Python
# 1. Fonction PGCD (Algorithme d'Euclide)
def pgcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

# 2. Fonction PPCM
def ppcm(a, b):
    return (a * b) // pgcd(a, b)

# 3. Procedure de simplification de fraction
def simplifier_fraction(num, den):
    g = pgcd(num, den)
    num_simp = num // g
    den_simp = den // g
    print("PGCD(", num, ",", den, ") =", g)
    print("Fraction irréductible :", num_simp, "/", den_simp)

# PROGRAMME PRINCIPAL
print("=== APPLICATION 1 : SYNCHRONISATION DES BUS ===")
freq_A = int(input("Fréquence Ligne A (minutes) : "))
freq_B = int(input("Fréquence Ligne B (minutes) : "))

intervalle = ppcm(freq_A, freq_B)

heure_dep = 7
minutes_totales = intervalle
heure_rencontre = heure_dep + (minutes_totales // 60)
minute_rencontre = minutes_totales % 60

print("Croisement dans :", intervalle, "minutes.")
print("Heure exacte :", heure_rencontre, "h :", minute_rencontre, "min")

print("\n=== APPLICATION 2 : SIMPLIFICATION DE FRACTION ===")
num = int(input("Numérateur (> 0) : "))
den = int(input("Dénominateur (> 0) : "))
simplifier_fraction(num, den)

2. Formule liant PPCM et PGCD ($A, B > 0$) ?
  • PPCM(A, B) = A + B - PGCD(A, B)
  • PPCM(A, B) = (A * B) // PGCD(A, B)
  • PPCM(A, B) = PGCD(A, B) // (A * B)
  • PPCM(A, B) = A * B * PGCD(A, B)

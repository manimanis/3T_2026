1. Objectifs & Déroulement de la Séance

Savoirs (Connaissances)
  • Connaître la définition du **PGCD** (Plus Grand Commun Diviseur) et du **PPCM** (Plus Petit Commun Multiple) de deux entiers $> 0$.
  • Étudier l'**Algorithme d'Euclide** par divisions euclidiennes successives ($\text{PGCD}(a, b) = \text{PGCD}(b, a \pmod b)$).
  • Connaître la relation mathématique fondamentale : $$\text{PPCM}(a, b) = \frac{a \times b}{\text{PGCD}(a, b)}$$
Savoir-faire (Compétences pratiques)
  • Concevoir les fonctions modulaires pgcd(a, b) et ppcm(a, b) en Python.
  • Appliquer le calcul du PGCD à la **simplification irréductible de fractions** ($\frac{num/g}{den/g}$).
  • Appliquer le calcul du PPCM à la **synchronisation d'événements périodiques** (ex: fréquences de départ des bus).

2. Algorithme d'Euclide & Relation PGCD / PPCM

L'algorithme d'Euclide permet d'obtenir le PGCD de deux entiers avec un nombre minimal d'opérations en remplaçant successivement $a$ et $b$ par $b$ et $a \pmod b$.

Diagramme Vectoriel : Algorithme d'Euclide & Formule du PPCM
Exemple Pratique de Traçage : PGCD(48, 18)
Étape Variable a Variable b Reste r = a Mod b Action / Mise à jour
1 48 18 12 a ← 18, b ← 12
2 18 12 6 a ← 12, b ← 6
3 12 6 0 b = 0 $\to$ Boucle terminée ! PGCD = 6

Activité 1 : Comparaison Détaillée (Soustractions vs Euclide)

Analyse Comparative de la Complexité pour $a = 1\ 000\ 000$ et $b = 2$

Pour comprendre la supériorité de l'algorithme d'Euclide, analysons la trace d'exécution détaillée des deux méthodes pour $a = 1\ 000\ 000$ et $b = 2$.

Méthode 1 : Soustractions Successives 500 000 ÉTAPES

Principe : Tant que $a \neq b$, on soustrait le plus petit du plus grand ($a \leftarrow a - b$).

Trace pas-à-pas des itérations :
- Étape 1 : $1\ 000\ 000 - 2 = 999\ 998$ ($a = 999\ 998, b = 2$)
- Étape 2 : $999\ 998 - 2 = 999\ 996$ ($a = 999\ 996, b = 2$)
- Étape 3 : $999\ 996 - 2 = 999\ 994$ ($a = 999\ 994, b = 2$)
... [ 499 995 itérations intermédiaires ] ...
- Étape 499 999 : $4 - 2 = 2$ ($a = 2, b = 2$)
- Étape 500 000 : $a = b = 2 \implies \text{PGCD} = 2$
Inconvénient Majeur : Exécute 500 000 soustractions ! Très lent si $a$ est très grand devant $b$.
Méthode 2 : Divisions d'Euclide 1 SEULE ÉTAPE

Principe : Tant que $b \neq 0$, on remplace $(a, b)$ par $(b, a \pmod b)$.

Trace pas-à-pas des itérations :
- Étape 1 : $1\ 000\ 000 \pmod 2 = 0$ ($r = 0$)
- Mise à jour : $a \leftarrow 2, b \leftarrow 0$
- $b = 0 \implies$ Fin de la boucle ! $\text{PGCD} = a = 2$
.
.
Avantage Énorme : Exécute 1 seule division ! $500\ 000 \times$ plus rapide.
Tableau Synthétique de Comparaison
Méthode Opération Récurrente Nombre d'Itérations ($a=10^6, b=2$) Efficacité de Calcul Verdict Ministériel
Soustractions Successives a ← a - b 500 000 soustractions Inappropriée ❌ Déconseillée pour les grands nombres
Divisions d'Euclide r ← a Mod b 1 seule division Maximale ✔️ Norme Officielle Ministérielle
Code Python Comparatif (À tester dans Thonny IDE)
# 1. Méthode par Soustractions (Lente)
def pgcd_soustractions(a, b):
    count = 0
    while a != b:
        if a > b:
            a = a - b
        else:
            b = b - a
        count += 1
    return a, count

# 2. Méthode d'Euclide (Rapide)
def pgcd_euclide(a, b):
    count = 0
    while b != 0:
        r = a % b
        a = b
        b = r
        count += 1
    return a, count

# Test comparatif
a, b = 1000000, 2
res1, it1 = pgcd_soustractions(a, b)
res2, it2 = pgcd_euclide(a, b)

print("Soustractions : PGCD =", res1, "en", it1, "itérations")  # 500 000 itérations
print("Euclide       : PGCD =", res2, "en", it2, "itération")   # 1 seule itération !

Implémentation Python Officielle (Thonny IDE)
# 1. Fonction PGCD (Algorithme d'Euclide)
def pgcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

# 2. Fonction PPCM
def ppcm(a, b):
    return (a * b) // pgcd(a, b)

# 3. Procedure de simplification de fraction
def simplifier_fraction(num, den):
    g = pgcd(num, den)
    num_simp = num // g
    den_simp = den // g
    print("PGCD(", num, ",", den, ") =", g)
    print("Fraction irréductible :", num_simp, "/", den_simp)

# PROGRAMME PRINCIPAL
print("=== APPLICATION 1 : SYNCHRONISATION DES BUS ===")
freq_A = int(input("Fréquence Ligne A (minutes) : "))
freq_B = int(input("Fréquence Ligne B (minutes) : "))

intervalle = ppcm(freq_A, freq_B)

heure_dep = 7
minutes_totales = intervalle
heure_rencontre = heure_dep + (minutes_totales // 60)
minute_rencontre = minutes_totales % 60

print("Croisement dans :", intervalle, "minutes.")
print("Heure exacte :", heure_rencontre, "h :", minute_rencontre, "min")

print("\n=== APPLICATION 2 : SIMPLIFICATION DE FRACTION ===")
num = int(input("Numérateur (> 0) : "))
den = int(input("Dénominateur (> 0) : "))
simplifier_fraction(num, den)

Synthèse du Cours

2. Boucles à condition d'arrêt

Répétitions pilotées par une expression booléenne lorsque le nombre d'itérations est inconnu d'avance.

Comparaison des Structures Répétitives
Structure Utilisation Condition de Contrôle Nombre d'Exécutions
Pour Nombre d'itérations connu d'avance. Automatique (Compteur d'itérations) Fixe ($Fin - Début + 1$)
Tant Que Nombre d'itérations inconnu. Condition de Poursuite (évaluée au début) $0$ à plusieurs fois ($0 \dots N$)
Répéter Nombre d'itérations inconnu. Condition d'Arrêt (évaluée à la fin) Au moins $1$ fois ($1 \dots N$)

Structure Tant Que (Algorithme & Python)

Le traitement est exécuté TANT QUE la condition de poursuite reste VRAIE.

Le traitement est répété JUSQU'À CE QUE la condition d'arrêt devienne VRAIE.

Recommandations Importantes
  1. Initialisation préalable : Les variables intervenant dans la condition d'une boucle while doivent être impérativement initialisées AVANT l'entrée dans la boucle.
  2. Mise à jour interne : La valeur contrôlant la condition doit obligatoirement être modifiée à l'intérieur de la boucle, sous peine de créer une boucle infinie.
  3. 🚫 Interdiction stricte de break : L'utilisation des instructions de sortie brutale (break, exit()) est strictement interdite lors des épreuves pratiques et du baccalauréat.

Activité 1 : Suppression de break & Contrôle de Saisie

Correction d'un Code Non Conforme

Transformons un script utilisant break en un code algorithmiquement propre et conforme aux exigences officielles.

Code Non Conforme 
# ❌ Interdit aux épreuves pratiques !
while True:
    val = int(input("Donner un nombre pair : "))
    if val % 2 == 0:
        break
    print("Invalide ! Le nombre doit être pair.")

print("Nombre valide :", val)
Inconvénient : Masque la condition logique d'arrêt de la boucle et viole les principes de programmation structurée.
Code Conforme 
# ✅ Conforme aux conventions
val = int(input("Donner un nombre pair : "))

# Condition de poursuite : le nombre est IMPAIR
while val % 2 != 0:
    print("Invalide ! Le nombre doit être pair.")
    val = int(input("Donner un nombre pair : "))

print("Nombre valide :", val)
Avantage : Première saisie préalable, puis réitération TANT QUE la donnée est invalide (`val % 2 != 0`).

Activité 2 : Jeu du Nombre Secret & Essais Limités

Problème Pratique Guidé

Énoncé du problème :

On souhaite concevoir un jeu interactif « Le Nombre Secret » sous Python :

  1. Le programme génère un nombre secret aléatoire compris entre 1 et 50 inclus (via randint(1, 50) du module random).
  2. Le joueur dispose de 6 essais maximum pour deviner le secret.
  3. À chaque proposition :
    • La saisie doit être strictement contrôlée dans $[1, 50]$.
    • Si la proposition est supérieure au secret, afficher "C'est MOINS !".
    • Si elle est inférieure, afficher "C'est PLUS !".
    • Si elle est égale, le jeu s'arrête immédiatement avec un message de victoire.
  4. Si les 6 essais sont épuisés sans succès, afficher un message de défaite et révéler le nombre secret.

Implémentation Python (Python IDE)
from random import randint

# Génération aléatoire du secret (1 à 50)
secret = randint(1, 50)
nb_essais = 0
trouve = False

# Boucle conditionnelle sans break
while nb_essais < 6 and not trouve:
    nb_essais += 1
    print("\n--- Essai N°", nb_essais, "/ 6 ---")
    
    # Contrôle de saisie du domaine [1, 50]
    essai = int(input("Proposez un nombre (1 à 50) : "))
    while not (1 <= essai <= 50):
        essai = int(input("Invalide ! Nombre entre 1 et 50 : "))
    
    # Évaluation de la proposition
    if essai == secret:
        trouve = True
    elif essai < secret:
        print("C'est PLUS !")
    else:
        print("C'est MOINS !")

# Bilan de fin de partie
if trouve:
    print("🎉 Bravo ! Trouvé en", nb_essais, "essai(s) !")
else:
    print("❌ Perdu ! Le secret était :", secret)

Évaluation Formative (Quiz Interactif)

1. Différence fondamentale entre Tant Que et Répéter ?
  • Répéter...Jusqu'à exécute le corps au moins une fois, Tant Que peut ne jamais l'exécuter
  • Tant Que s'exécute toujours au moins 10 fois
  • Répéter n'a pas besoin de condition
  • Elles sont parfaitement identiques
2. Boucle conditionnelle en Python ?
  • repeat...until
  • while condition :
  • loop...until
  • do...while
3. Rôle du contrôle de saisie ?
  • Trier un tableau
  • Calculer une moyenne
  • Valider la saisie et rejeter les valeurs incorrectes
  • Convertir les types
4. Quand s'arrête 'Répéter ... Jusqu'à (Condition)' ?
  • Dès que la Condition devient VRAIE
  • Tant que la Condition est VRAIE
  • Après 10 itérations
  • Sur saturation mémoire
5. Conséquence si la condition d'un while reste toujours VRAIE ?
  • Le programme entre dans une boucle infinie
  • Le programme s'arrête au bout de 5 secondes
  • Python lève une exception de syntaxe
  • La boucle s'exécute 0 fois

Modulation PWM & Servomoteur

Principe de la PWM

La PWM fait osciller une broche entre $0\,\text{V}$ et $3.3\,\text{V}$ pour délivrer une puissance apparente variable.

Rapport Cyclique (Duty Cycle $D$) : $$D = \frac{t_{\text{on}}}{T} \times 100\% \quad (T = \frac{1}{f})$$ Résolution ESP32 MicroPython : 10 bits ($0 \dots 1023$).

Commande du Servomoteur SG90 ($50\,\text{Hz}$, $T = 20\,\text{ms}$)

Angle ($^\circ$) Impulsion ($t_{\text{on}}$) Rapport ($D$) Duty MicroPython (0-1023)
0° 1.0 ms 5.0 % 26
90° 1.5 ms 7.5 % 77
180° 2.0 ms 10.0 % 123

Scripts MicroPython

Commande du Servomoteur SG90 (GPIO 13)

from machine import Pin, PWM

servo = PWM(Pin(13), freq=50)

def poser_angle(angle):
    duty_val = int(26 + (angle / 180.0) * (123 - 26))
    servo.duty(duty_val)

poser_angle(90)  # Position 90°

Buzzer Piézoélectrique (GPIO 12)

from machine import Pin, PWM
import time

buzzer = PWM(Pin(12))

def bip(freq_hz, duree_s):
    buzzer.freq(freq_hz)
    buzzer.duty(512)  # Puissance 50%
    time.sleep(duree_s)
    buzzer.duty(0)

bip(440, 0.5)  # Note LA (440 Hz) pendant 0.5 s

Évaluation Formative

QCM d'Auto-évaluation

1. Définition du rapport cyclique (Duty Cycle) d'un signal PWM :
  • Pourcentage de temps où le signal est à l'état HAUT
  • Fréquence du processeur
  • Nombre de clignotements par minute
  • Résistance du composant
2. Plage angulaire du servomoteur SG90 standard :
  • 0° à 360° continu
  • 0° à 180°
  • -90° à +90°
  • 0° à 90°
3. Paramètre modifiant la hauteur du son sur un buzzer :
  • Rapport cyclique
  • Tension d'alimentation
  • Fréquence du signal PWM (Hz)
  • Masse GND
4. Fréquence PWM requise pour piloter le SG90 :
  • 50 Hz (Période 20 ms)
  • 1000 Hz
  • 1 Hz
  • 10 000 Hz
5. Configuration d'une sortie PWM à 1000 Hz sur GPIO 4 :
  • PWM(Pin(4), freq=1000)
  • Pin(4).pwm(1000)
  • AnalogOut(4, 1000)
  • Servo(4)

La Modulation de Largeur d'Impulsion (PWM)

1. Principe de la PWM (Pulse Width Modulation)

La **PWM** permet à un microcontrôleur numérique de délivrer une puissance variable en faisant osciller la broche entre $0\,\text{V}$ et $3.3\,\text{V}$ à haute fréquence.

Formule du Rapport Cyclique (Duty Cycle $D$) : $$D = \frac{t_{\text{on}}}{T} \times 100\% \quad \text{avec} \quad T = \frac{1}{f}$$ En MicroPython sur ESP32, la résolution est codée sur **10 bits** ($0 \dots 1023$).

2. Commande du Servomoteur SG90 ($50\,\text{Hz}$)

Le servomoteur SG90 se pilote avec une impulsion de largeur variable répétée à **$50\,\text{Hz}$** ($T = 20\,\text{ms}$) :

Angle ($^\circ$) Durée de l'Impulsion ($t_{\text{on}}$) Rapport Cyclique ($D$) Valeur Duty MicroPython (0-1023)
0° 1.0 ms 5.0 % 26
90° 1.5 ms 7.5 % 77
180° 2.0 ms 10.0 % 123

Scripts MicroPython & C++

1. Fonction de commande du Servomoteur en MicroPython

from machine import Pin, PWM
import time

# Initialisation PWM sur GPIO 13 à 50 Hz
servo = PWM(Pin(13), freq=50)

def poser_angle(angle):
    # Formule de conversion d'angle (0°..180°) vers duty (26..123)
    duty_val = int(26 + (angle / 180.0) * (123 - 26))
    servo.duty(duty_val)

# Exemple : Ouvrir le servo à 90 degrés
poser_angle(90)

2. Génération de Bips Sonores sur Buzzer Piezo

from machine import Pin, PWM
import time

buzzer = PWM(Pin(12))

def bip_alarme(frequence_hz, duree_sec):
    buzzer.freq(frequence_hz)
    buzzer.duty(512) # 50% de puissance
    time.sleep(duree_sec)
    buzzer.duty(0)   # Éteindre

# Émettre une note LA à 440 Hz pendant 0.5 sec
bip_alarme(440, 0.5)

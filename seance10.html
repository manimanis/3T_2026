Sujet de l'Épreuve (STEG)

Mise en situation : Bilan Énergétique STEG

Société Tunisienne de l'Électricité et du Gaz (STEG)

Étude statistique de la consommation électrique d'un foyer sur $N$ jours ($7 \le N \le 30$).

Travail demandé :

  1. saisir_taille(min_v, max_v) : Saisit et valide $N \in [7, 30]$ (Fonction).
  2. saisir_consommations(T, n) : Remplit $T$ avec les valeurs dans $[0.5, 50.0]$ kWh (Procédure).
  3. afficher_consommations(T, n) : Affiche : Jour i : X kWh (Procédure).
  4. calculer_moyenne(T, n) : Calcule et retourne la moyenne (Fonction).
  5. rechercher_pic(T, n) : Retourne l'indice du jour maximal (Fonction).
  6. compter_surconsommations(T, n, seuil) : Compte les jours où $T[i] > seuil$ (Fonction).

Implémentation Python Officielle (Python IDE)
from numpy import array

def saisir_taille(min_v, max_v):
    taille = int(input("Donner le nombre de jours (" + str(min_v) + " à " + str(max_v) + ") : "))
    while not (min_v <= taille <= max_v):
        taille = int(input("Invalide ! Saisir N entre " + str(min_v) + " et " + str(max_v) + " : "))
    return taille

def saisir_consommations(T, n):
    print("\n--- Saisie des consommations quotidiennes ---")
    for i in range(n):
        val = float(input("Consommation Jour " + str(i + 1) + " (0.5 à 50.0 kWh) : "))
        while not (0.5 <= val <= 50.0):
            val = float(input("Invalide ! Saisir une valeur entre 0.5 et 50.0 kWh : "))
        T[i] = val

def afficher_consommations(T, n):
    print("\n=== RELEVÉ QUOTIDIEN DE CONSOMMATION ===")
    for i in range(n):
        print("Jour", i + 1, ":", T[i], "kWh")

def calculer_moyenne(T, n):
    somme = 0.0
    for i in range(n):
        somme += T[i]
    return somme / n

def rechercher_pic(T, n):
    idx_max = 0
    for i in range(1, n):
        if T[i] > T[idx_max]:
            idx_max = i
    return idx_max

def compter_surconsommations(T, n, seuil):
    nb = 0
    for i in range(n):
        if T[i] > seuil:
            nb += 1
    return nb

# PROGRAMME PRINCIPAL
n = saisir_taille(7, 30)

Conso = array([float()] * n)

saisir_consommations(Conso, n)
afficher_consommations(Conso, n)

moy_conso = calculer_moyenne(Conso, n)
jour_pic = rechercher_pic(Conso, n)
nb_jours_eleves = compter_surconsommations(Conso, n, moy_conso)

print("\n=== BILAN ÉNERGÉTIQUE DE LA PÉRIODE ===")
print("Consommation moyenne quotidienne :", round(moy_conso, 2), "kWh")
print("Pic de consommation               : Jour", jour_pic + 1, "avec", Conso[jour_pic], "kWh")
print("Nombre de jours > moyenne         :", nb_jours_eleves, "jour(s)")

Pièges Classiques

Pièges à Éviter

Piège 1 : Usage de `break`

Interdit aux épreuves. Utiliser une condition booléenne dans la boucle while.

Piège 2 : `print(T)`

Afficher chaque élément via une boucle : for i in range(n): print(T[i]).

Piège 3 : `max = 0`

Ne pas initialiser à 0. Poser idx_max = 0 et boucler à partir de i = 1.

Tableaux 1D : Comptages conditionnels & Filtrage sélectif

Gestion rigoureuse du double indice, transfert sélectif, séparation pairs/impairs et tassement

OBJECTIFS D'APPRENTISSAGE

Asynchronisme des indices

Comprendre pourquoi l'indice de parcours source $i$ avance inconditionnellement alors que l'indice destination $j$ n'avance qu'en cas de sélection.

Taille effective

Conserver la taille utile $j$ du tableau cible statique et afficher strictement les éléments transférés sans afficher les cases résiduelles.

Éclatement & Tassement

Répartir les éléments d'un tableau vers deux sous-ensembles et compacter un tableau in-place en éliminant les valeurs indésirables.

Patron de conception officiel : Transfert sélectif avec double indice

Pseudo-code algorithmique 
j ← 0
Pour i de 0 à N - 1 Faire
  Si (T1[i] >= 10.0) Et (T1[i] <= 20.0) Alors
    T2[j] ← T1[i]
    j ← j + 1
  Fin Si
Fin Pour
tailleT2 ← j
Code Python équivalent 
j = 0
for i in range(N):
    if 10.0 <= T1[i] <= 20.0:
        T2[j] = T1[i]
        j += 1
taille_T2 = j

# Affichage des cases utiles uniquement :
for k in range(taille_T2):
    print(f"T2[{k}] = {T2[k]}")

Activité 3 — Conception algorithmique du filtrage par intervalle

Maîtrise

On souhaite extraire d'un tableau $T1$ de $N$ réels toutes les valeurs comprises dans l'intervalle $[10.0 ; 20.0]$ et les stocker dans $T2$.

  1. Pourquoi la taille maximale allouée pour $T2$ doit-elle être égale à $N$ ?
  2. Écrire l'algorithme de transfert complet et préciser la condition d'appartenance à l'intervalle.
  3. Que vaut la taille finale du tableau $T2$ si aucun élément ne vérifie le critère ?

PALIER 🔴 AVANCÉ — Éclatement & Tassement

Activité 5 — Éclatement d'un tableau en deux sous-tableaux

Dépassement

Soit un tableau $T$ de $N$ entiers. On souhaite éclater $T$ en deux tableaux distincts :

  • TPairs : contenant tous les entiers pairs ($T[i] \pmod 2 = 0$).
  • TImpairs : contenant tous les entiers impairs ($T[i] \pmod 2 \neq 0$).
  1. Expliquer pourquoi deux compteurs distincts $j_1$ et $j_2$ sont indispensables.
  2. Écrire l'algorithme qui parcourt $T$ une seule fois et répartit les nombres dans les deux tableaux.
  3. Vérifier que la relation arithmétique suivante est toujours satisfaite à la fin du traitement : $j_1 + j_2 = N$.
Rédigez l'algorithme de séparation sur votre cahier.

Activité 6 — Tassement in-place d'un tableau (suppression des zéros)

Dépassement

Soit un tableau contenant des zéros au milieu de nombres non nuls (ex: [4, 0, 9, 0, 0, 7, 2]). On désire compacter le tableau vers la gauche pour regrouper tous les nombres non nuls sans utiliser de second tableau.

  1. Concevoir l'algorithme de tassement in-place en utilisant $i$ comme lecteur et $j$ comme pointeur d'écriture dans le même tableau $T$ : si $T[i] \neq 0$, alors $T[j] \leftarrow T[i]$ et $j \leftarrow j + 1$.
  2. Remplir les cases résiduelles de $j$ à $N-1$ par des zéros.
  3. Dérouler l'algorithme sur le tableau exemple et constater l'efficacité mémoire.
Rédigez l'algorithme de tassement in-place sur votre cahier.

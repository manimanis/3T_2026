Passage de Tableaux `numpy` en Paramètre

- En Algorithmique : On indique le symbole @ devant le tableau lorsque le module le remplit ou le modifie : Procédure Remplir (@T : Tableau de N Entier, n : Entier).
- En Python : Les tableaux de la bibliothèque numpy sont passés par adresse par défaut. La signature s'écrit simplement def remplir(T, n): et toute modification T[i] = ... impacte le tableau d'origine.

Activité 1 : Application des Fonctions Prédéfinies (`generer_code_eleve`)

Génération Automatique de Code d'Accès Élève

Écrire une fonction Python generer_code_eleve(nom, annee) qui prend le nom d'un élève et son année de naissance, et retourne un code au format : 3 premières lettres en Majuscules + Année.

Code Python (Fonction & Test) 
def generer_code_eleve(nom, annee):
    # Extraction des 3 premiers caractères en majuscules
    prefixe = nom[:3].upper()
    # Concaténation avec l'année convertie en chaîne
    code = prefixe + str(annee)
    return code

# Test du programme principal
nom = "ben ali"
annee = 2008
code_eleve = generer_code_eleve(nom, annee)

print("Nom élève :", nom)
print("Code généré :", code_eleve)  # Affiche BEN2008
Analyse des Fonctions Prédéfinies Utilisées
  • nom[:3] : Découpage de chaîne (*slicing*) pour extraire les 3 premiers caractères (indices 0 à 2).
  • .upper() : Conversion du prétexte en lettres majuscules (ex: `"ben"` $\to$ `"BEN"`).
  • str(annee) : Conversion de l'entier `2008` en chaîne de caractères `"2008"`.
  • + : Opération de concaténation des deux chaînes.

Implémentation Python (Python IDE)
from numpy import array
from random import randint

def saisir_taille(min_v, max_v):
    taille = int(input("Taille (" + str(min_v) + "-" + str(max_v) + ") : "))
    while not (min_v <= taille <= max_v):
        taille = int(input("Invalide ! Recommencer : "))
    return taille

def remplir_notes_aleatoires(T, n):
    for i in range(n):
        T[i] = randint(0, 20)  # Tirage aleatoire

def afficher_tableau(T, n, msg):
    print("\n=== " + msg + " ===")
    for i in range(n):
        print("Élément [" + str(i) + "] =", T[i])

def calculer_moyenne(T, n):
    somme = 0
    for i in range(n):
        somme += T[i]
    return somme / n

def extraire_admis(T_src, n, T_dest):
    j = 0
    for i in range(n):
        if T_src[i] >= 10:
            T_dest[j] = T_src[i]
            j += 1
    return j  # Retourne la taille effective M

# PROGRAMME PRINCIPAL
n = saisir_taille(5, 40)

T_notes = array([0] * n)
T_admis = array([0] * n)

remplir_notes_aleatoires(T_notes, n)
afficher_tableau(T_notes, n, "NOTES GÉNÉRÉES")

moy_classe = calculer_moyenne(T_notes, n)
print("\nMoyenne générale :", round(moy_classe, 2), "/ 20")

m = extraire_admis(T_notes, n, T_admis)
afficher_tableau(T_admis, m, "NOTES ADMIS")
print("\nTotal admis :", m, "/", n)

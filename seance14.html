Propriétés du PPCM & Fractions

Algorithme Officiel d'Euclide (Divisions successives)

Pseudo-code officiel 
Fonction PGCD_Euclide(a, b : Entier) : Entier
Début
  Tant Que (b ≠ 0) Faire
    reste ← a Mod b
    a ← b
    b ← reste
  Fin Tant Que
  Retourner a
Fin
Traduction Python 
def pgcd_euclide(a: int, b: int) -> int:
    while b != 0:
        reste = a % b
        a = b
        b = reste
    return a

def ppcm(a: int, b: int) -> int:
    return (a * b) // pgcd_euclide(a, b)

Activité 4 — Fonction de calcul du Plus Petit Commun Multiple (PPCM)

Maîtrise

Pour deux entiers strictement positifs $a$ et $b$, le PPCM est relié au PGCD par l'identité mathématique :

$$\text{PPCM}(a, b) = \frac{a \times b}{\text{PGCD}(a, b)} = (a \times b) \text{ Div } \text{PGCD}(a, b)$$
  1. Pourquoi utilise-t-on la division entière Div (//) plutôt que la division réelle / ?
  2. Écrire la fonction modulaire PPCM(a, b : Entier) : Entier qui appelle directement la fonction PGCD_Euclide.
  3. Calculer $\text{PPCM}(15, 20)$ et vérifier que le résultat vaut bien 60.
Notez la fonction PPCM sur votre cahier.

Tri d'un Tableau – Le Tri à Bulles

3e Sc. • 1h30

Fiche Pédagogique

1. Objectifs & Chronogramme

Savoirs
  • Principe du **Tri à Bulles** : comparer et permuter deux éléments adjacents $T[j]$ et $T[j+1]$.
  • Dynamique : à chaque passage $i$, le plus grand élément remonte à sa position finale.
  • Permutation sécurisée via une variable intermédiaire `aux`.
Savoir-faire
  • Procédure tri_a_bulles(T, n) en ordre croissant et décroissant.
  • Tri synchrone de **tableaux parallèles** (noms et temps).
  • Règle ministérielle : **aucun `break`** dans les boucles de tri.

Synthèse du Cours

2. Tri à Bulles & Permutation

Effectue $N - 1$ passages en comparant les paires adjacentes $T[j]$ et $T[j+1]$ et en les permutant si nécessaire.

Diagramme Vectoriel : Remontée des Bulles & Permutation
Permutation en 3 Étapes

Pour échanger $T[j]$ et $T[j+1]$ sans écrasement, une variable `aux` est obligatoire :
1. aux ← T[j]  |  2. T[j] ← T[j + 1]  |  3. T[j + 1] ← aux

Activité 1 : Traçage d'un Tri à Bulles Pas-à-Pas

Exemple sur le Tableau $T = [15, 3, 8, 2]$ ($N = 4$)

Historique des Passages de la Boucle Extérieure `i`
Passage `i` Intervalle `j` Comparaisons & Permutations Effectuées État du Tableau à la fin du passage
État Initial - Aucune [15, 3, 8, 2]
i = 0 j de 0 à 2 15 > 3 (Échange) $\to$ 15 > 8 (Échange) $\to$ 15 > 2 (Échange) [3, 8, 2, 15] (15 est placé)
i = 1 j de 0 à 1 3 < 8 (Pas d'échange) $\to$ 8 > 2 (Échange) [3, 2, 8, 15] (8 est placé)
i = 2 j = 0 3 > 2 (Échange) [2, 3, 8, 15] Tableau Trié !

Implémentation Python Officielle (Python IDE)
from numpy import array

def tri_a_bulles_synchrone(Noms, Temps, n):
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if Temps[j] > Temps[j + 1]:
                # Permutation des temps
                aux_t = Temps[j]
                Temps[j] = Temps[j + 1]
                Temps[j + 1] = aux_t
                
                # Permutation synchrone des noms
                aux_n = Noms[j]
                Noms[j] = Noms[j + 1]
                Noms[j + 1] = aux_n

# PROGRAMME PRINCIPAL
n = int(input("Nombre de coureurs (4 à 30) : "))
Noms = array([''] * n, dtype='U30')
Temps = array([float()] * n)

for i in range(n):
    Noms[i] = input("Nom du coureur N° " + str(i+1) + " : ")
    t = float(input("Temps de " + Noms[i] + " (en sec) : "))
    while t <= 0.0:
        t = float(input("Invalide ! temps > 0 : "))
    Temps[i] = t

tri_a_bulles_synchrone(Noms, Temps, n)

print("\n🏆 PODIUM DES MÉDAILLÉS 🏆")
print("🥇 Or     :", Noms[0], "(", Temps[0], "sec )")
print("🥈 Argent :", Noms[1], "(", Temps[1], "sec )")
print("🥉 Bronze :", Noms[2], "(", Temps[2], "sec )")

  • Placer le plus petit au début
  • Insérer chaque élément à sa place
  • Diviser le tableau en sous-tableaux
2. Arrêter le tri si le tableau est déjà ordonné ?

  • Variable booléenne de permutation (ex: Permut)
  • Supprimer la boucle externe
  • Doubler la taille
3. Complexité pire cas du Tri à Bulles ?
  • O(N)
  • O(log N)
  • O(N^2)
  • O(1)
4. Résultat du tout premier passage ?
  • Le plus grand élément est placé à la fin du tableau
  • Le tableau entier est trié
  • Le plus petit élément est éliminé
  • La moitié du tableau est triée
5. Séquence correcte de permutation avec Aux ?
  • Aux = A ; A = B ; B = Aux
  • A = B ; B = A
  • Aux = B ; B = Aux ; A = B
  • A = Aux ; B = A ; Aux = B

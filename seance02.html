Synthèse du Cours

2. Les Structures Conditionnelles

Une structure conditionnelle permet d'exécuter un bloc d'instructions uniquement si une condition logique est vraie (True). On distingue trois formes de structures conditionnelles :

Forme Réduite
Algorithme 
Si Condition Alors
    Traitement
FinSi
Python (Instruction if) 
if condition:
    traitement
Exemple concret Algorithme : 
Si note >= 10 Alors
    Ecrire("Admis")
FinSi
Python : 
if note >= 10:
    print("Admis")
Forme Alternative
Algorithme 
Si Condition Alors
    Traitement1
Sinon
    Traitement2
FinSi
Python (Instructions if ... else) 
if condition:
    traitement1
else:
    traitement2
Exemple concret Algorithme : 
Si n mod 2 = 0 Alors
    Ecrire("Pair")
Sinon
    Ecrire("Impair")
FinSi
Python : 
if n % 2 == 0:
    print("Pair")
else:
    print("Impair")
Forme Généralisée
Algorithme 
Si Condition1 Alors
    Traitement1
Sinon Si Condition2 Alors
    Traitement2
Sinon
    TraitementN
FinSi
Python (Instruction elif) 
if condition1:
    traitement1
elif condition2:
    traitement2
else:
    traitementN
Exemple concret Algorithme : 
Si n > 0 Alors
    Ecrire("Positif")
Sinon Si n < 0 Alors
    Ecrire("Négatif")
Sinon
    Ecrire("Nul")
FinSi
Python : 
if n > 0:
    print("Positif")
elif n < 0:
    print("Négatif")
else:
    print("Nul")

3. La Structure Itérative Complète

La structure itérative Pour est utilisée lorsque le nombre d'itérations est connu à l'avance.

Algorithme
Pour compteur de Début à Fin [Pas = v_pas] Faire
    Traitement
Fin Pour
Python (Fonction range)
for compteur in range(début, fin + 1, pas):
    traitement
Diagramme de flux d'exécution : Boucle Pour / for range()
Piège classique en Python : Exclusion de la borne finale !

La borne finale dans range(début, fin, pas) est toujours exclue :

  • Ordre croissant (de 1 à N inclus) : Écrire range(1, N + 1) (le pas vaut 1 par défaut).
  • Ordre décroissant (de N à 1 inclus) : Écrire range(N, 0, -1) (la borne 0 est exclue, l'itération s'arrête bien à 1 avec un pas négatif de -1).

Les Motifs Classiques : Compteur, Accumulateur & Produit

En algorithmique et programmation, un motif classique est un schéma de calcul récurrent dans une boucle. Pour fonctionner correctement, chaque motif exige deux étapes clés :

  • l'initialisation obligatoire AVANT d'entrer dans la boucle (élément neutre)
  • la mise à jour À L'INTÉRIEUR de la boucle
1. Le Compteur

Servant à dénombrer des éléments ou des événements satisfaisant une condition.

Initialisation : c ← 0
Mise à jour : c ← c + 1
Principe : L'élément neutre du comptage est 0. À chaque élément valide trouvé, on ajoute 1 au compteur.
Exemple Concret :

Compter les nombres pairs entre 1 et N :

nb_pairs = 0
n = int(input("Donner N : "))
for i in range(1, n + 1):
    if i % 2 == 0:
        nb_pairs = nb_pairs + 1
2. L'Accumulateur (Somme)

Servant à cumuler la somme de plusieurs valeurs successives.

Initialisation : somme ← 0
Mise à jour : somme ← somme + val
Principe : L'élément neutre de l'addition est 0. À chaque tour, on ajoute la nouvelle valeur à la somme totale accumulée.
Exemple Concret :

Calculer la somme des entiers de 1 à N :

somme = 0
n = int(input("Donner N : "))
for i in range(1, n + 1):
    somme = somme + i
3. Le Produit Cumulé

Servant à multiplier successivement une série de facteurs (ex: Factorielle).

Initialisation : p ← 1
Mise à jour : p ← p * val
Principe : L'élément neutre de la multiplication est 1 (initialiser à 0 annulerait tout le produit !).
Exemple Concret :

Calculer la factorielle de N (N!) :

fact = 1
n = int(input("Donner N : "))
for i in range(1, n + 1):
    fact = fact * i

Activité 2 : Résolution du Problème - Salaire Mensuel Vendeur (30 min)

Énoncé de l'exercice :

Une entreprise commerciale calcule le salaire mensuel net de ses vendeurs sur une période de N jours ouvrables (saisi par l'utilisateur).

  • Le salaire de base quotidien est de 35.000 DT.
  • Pour chaque jour i (1 <= i <= N), l'utilisateur saisit le nombre de ventes réalisées.
  • Si le nombre de ventes d'un jour est supérieur à 10, le vendeur touche une prime journalière de 15.000 DT.
  • À la fin du mois, si le total des ventes réalisées dépasse 150 articles, une prime de performance globale de 100.000 DT est ajoutée au salaire net.

  • Données d'entrée (Entrées) :
    • n : Nombre de jours ouvrables (Entier)
    • nb_ventes : Ventes quotidiennes (Entier, saisi N fois)
  • Données de sortie (Sorties) :
    • total_ventes : Total d'articles vendus (Entier)
    • salaire_net : Salaire mensuel net (Réel)
  • Traitements :
    1. Initialiser total_ventes ← 0 et salaire_net ← 0.0.
    2. Pour chaque jour i de 1 à n :
      • total_ventes ← total_ventes + nb_ventes
      • salaire_net ← salaire_net + BASE_JOUR
      • Si nb_ventes > 10 Alors salaire_net ← salaire_net + PRIME_JOUR
    3. Si total_ventes > 150 Alors salaire_net ← salaire_net + PRIME_GLOBALE

script_vendeur.py 
# Constantes
BASE_JOUR = 35.000
PRIME_JOUR = 15.000
PRIME_GLOBALE = 100.000

# Entrée principale
n = int(input("Donner le nombre de jours ouvrables (N) : "))

# Initialisation des accumulateurs
total_ventes = 0
salaire_net = 0.0

# Boucle pour traiter chaque jour
for i in range(1, n + 1):
    nb_ventes = int(input("Nombre de ventes pour le jour " + str(i) + " : "))
    
    total_ventes = total_ventes + nb_ventes
    salaire_net = salaire_net + BASE_JOUR
    
    if nb_ventes > 10:
        salaire_net = salaire_net + PRIME_JOUR

# Test de la prime globale
if total_ventes > 150:
    salaire_net = salaire_net + PRIME_GLOBALE
    print("Félicitations ! Prime globale de 100.000 DT accordée.")

# Affichage des résultats
print("\n--- BILAN MENSUEL ---")
print("Total d'articles vendus :", total_ventes)
print("Salaire net mensuel :", salaire_net, "DT")

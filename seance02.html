Les structures itératives non bornées : La boucle Tant Que

Contrôle de saisie robuste, condition d'arrêt et itérations non bornées — Algorithmique & Python (3e Sciences)

CADRE THÉORIQUE — La boucle Tant Que

Règle fondamentale : Lorsque le nombre de répétitions n'est pas connu à l'avance et dépend d'une condition dynamique qui évolue au cours du traitement, on utilise une structure itérative à condition d'arrêt (boucle non bornée).

Syntaxe Algorithmique

Tant que Condition Faire
  Traitements
Fin Tant que
  • La condition est évaluée avant d'entrer dans la boucle (pré-condition).
  • Si la condition est fausse au départ, le corps n'est jamais exécuté.

Traduction Python 3

while Condition:
    Traitements
  • Règle d'or : La variable de contrôle doit impérativement être initialisée avant le while et mise à jour à l'intérieur.
  • Interdiction formelle : Il est strictement interdit d'utiliser break pour forcer la sortie d'une boucle.

Activité 4 — Débogage d'une boucle infinie (erreur de terminaison)

Maîtrise · 15 min

Un élève a écrit le script Python ci-dessous pour forcer la saisie d'un entier strictement positif. Lorsqu'il saisit une valeur négative (ex: -3), la console affiche indéfiniment "Valeur invalide !" et la machine semble bloquée.

Script Python erroné
# Saisie d'un entier strictement positif
n = int(input("Donner un entier positif : "))
while n <= 0:
    print("Valeur invalide !")

print("Merci, vous avez saisi :", n)
  1. Expliquer précisément pourquoi ce script provoque une boucle infinie.
  2. Quelle instruction obligatoire manque-t-il à l'intérieur du bloc while pour assurer la terminaison de l'algorithme ?

Activité 6 — Modélisation scientifique : Décroissance radioactive et Demi-vie

Défi Avancé · 15 min

Contexte physique : Un échantillon radioactif contient initialement $N_0 = 100\,000$ noyaux instables. Chaque année, par désintégration nucléaire, le nombre de noyaux diminue de $5\%$ par rapport à l'année précédente : $$N_{t+1} = N_t \times (1 - 0.05) = N_t \times 0.95$$ La période radioactive (ou demi-vie) correspond à la durée nécessaire pour que le nombre de noyaux restants devienne strictement inférieur à la moitié de la quantité initiale, soit $N < N_0 / 2 = 50\,000$.

  1. Identifier la variable d'accumulation temporelle (nombre d'années) et la condition d'arrêt de la simulation.
  2. Écrire l'algorithme complet DemiVie utilisant une boucle Tant Que pour déterminer le nombre d'années nécessaires pour atteindre la demi-vie.
  3. Dresser le Tableau de Déclaration des Objets (TDO).
  4. Implémenter et exécuter ce programme sous Python. Quel est le résultat obtenu ? (Vérifier que la demi-vie est d'environ 14 ans).
Rédigez l'algorithme complet, le TDO et le résultat du calcul de demi-vie sur votre cahier.

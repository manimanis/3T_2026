Boucle Tant Que (while)

Pré-condition, boucle non bornée et cas 0 itération — 3e Sciences

Cadre théorique

Règle de choix
Nombre d'itérations inconnu à l'avance $\rightarrow$ utiliser Tant que (boucle non bornée). La boucle Pour est réservée aux répétitions prédéterminées.

Syntaxe Algorithmique

Tant que Condition Faire
  Traitements
Fin Tant que
  • Évaluation avant exécution (pré-condition).
  • Condition fausse au départ $\implies$ 0 itération.

Traduction Python

while Condition:
    Traitements
  • Variable de contrôle : initialisée avant, mise à jour dans la boucle.
  • Utilisation de break interdite.

Activité 2 — Algorithme & Trace comparée Conception

Tracer et comparer sur votre cahier :

  1. Cas nominal ($U = 100.0\text{ V}$) :
    • $t=0 : 100.0 \ge 20.0$ (Vrai) $\rightarrow U=50.0, \text{duree}=1$.
    • $t=1 : 50.0 \ge 20.0$ (Vrai) $\rightarrow U=25.0, \text{duree}=2$.
    • $t=2 : 25.0 \ge 20.0$ (Vrai) $\rightarrow U=12.5, \text{duree}=3$.
    • $t=3 : 12.5 \ge 20.0$ (Faux) $\rightarrow$ Arrêt : $12.5\text{ V}$, $3\text{ s}$.
  2. Cas 0 itération ($U = 14.0\text{ V}$) :
    • Entrée : $14.0 \ge 20.0$ (Faux d'emblée).
    • 0 itération $\rightarrow$ Sortie directe : $14.0\text{ V}$, $0\text{ s}$.
Synthèse didactique
Tant Que s'exécute de 0 à $N$ fois. Si la condition est fausse à l'entrée, le corps est ignoré (0 itération).

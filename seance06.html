2. Les 3 Motifs Algorithmiques Fondamentaux sur Tableau 1D

Le parcours d'un tableau permet d'effectuer des calculs cumulatifs, des filtres et des recherches d'extrémums en parcourant les éléments de l'indice 0 à $N-1$.

Diagramme Vectoriel : Les 3 Motifs de Traitement sur Tableau 1D
Motif 1 : Somme & Moyenne
Algorithme
somme ← 0.0
Pour i de 0 à n - 1 Faire
    somme ← somme + T[i]
Fin Pour
moyenne ← somme / n
Python

    somme += T[i]
moyenne = somme / n
Motif 2 : Max / Min
Algorithme
max_val ← T[0]
Pour i de 1 à n - 1 Faire
    Si (T[i] > max_val) Alors
        max_val ← T[i]
    FinSi
Fin Pour
Python
max_val = T[0]
for i in range(1, n):
    if T[i] > max_val:
        max_val = T[i]
Motif 3 : Comptage
Algorithme
nb_admis ← 0
Pour i de 0 à n - 1 Faire
    Si (T[i] ≥ 10.0) Alors
        nb_admis ← nb_admis + 1
    FinSi
Fin Pour
Python
nb_admis = 0
for i in range(n):
    if T[i] >= 10.0:
        nb_admis += 1
Règle d'Or sur l'Initialisation du Max et du Min

Ne jamais initialiser la variable Max à 0 ! Si toutes les valeurs du tableau sont négatives (ex: températures [-5.5, -12.0, -2.3]), 0.0 restera supérieur à toutes les cases et le résultat sera faux. On initialisera toujours max_val ← T[0] et min_val ← T[0].

Activité 1 : Analyse de Bug d'Initialisation

Correction d'un Bug d'Initialisation Fréquent

Pourquoi ce script donne-t-il un résultat erroné lorsque toutes les températures sont négatives ?

Code Erroné (Initialisation à 0.0) 
# ❌ Bug sur les séries négatives !
from numpy import array

T = array([-5.5, -12.0, -2.3, -8.1])
max_temp = 0.0  # ERREUR CRITIQUE !

for i in range(len(T)):
    if T[i] > max_temp:
        max_temp = T[i]

# Affiche à tort: "Max = 0.0" au lieu de -2.3 !
print("Température max :", max_temp)
Code Corrigé (Initialisation sur T[0]) 
# ✅ Correction Conforme (Tableau numpy.array)
from numpy import array

T = array([-5.5, -12.0, -2.3, -8.1])
max_temp = T[0]

for i in range(1, len(T)):
    if T[i] > max_temp:
        max_temp = T[i]

# Affiche correctement: "Max = -2.3"
print("Température max :", max_temp)

Activité 2 : Analyse Statistique des Notes d'une Classe

Problème Pratique Guidé

Énoncé du problème :

Un enseignant d'informatique souhaite effectuer l'analyse statistique des notes obtenues par une classe de $N$ élèves ($5 \le N \le 30$) lors d'un devoir pratique.

  1. Saisir le nombre d'élèves $N$ avec contrôle de saisie ($5 \le N \le 30$).
  2. Remplir un tableau Notes avec les notes des élèves (réels compris dans $[0.0, 20.0]$).
  3. Calculer et afficher : la moyenne de la classe, la note maximale, la note minimale, le nombre d'admis ($\ge 10.0$) et le taux de réussite %.

Implémentation Python (Thonny IDE)
from numpy import array

n = int(input("Donner N (5 à 30) : "))
while not (5 <= n <= 30):
    n = int(input("Invalide ! Saisir N (5 à 30) : "))

Notes = array([0.0] * n)

for i in range(n):
    note = float(input("Note N° " + str(i + 1) + " : "))
    while not (0.0 <= note <= 20.0):
        note = float(input("Invalide (0 à 20) : "))
    Notes[i] = note

somme = Notes[0]
max_note = Notes[0]
min_note = Notes[0]

if Notes[0] >= 10.0:
    nb_admis = 1
else:
    nb_admis = 0

for i in range(1, n):
    somme += Notes[i]
    if Notes[i] > max_note:
        max_note = Notes[i]
    if Notes[i] < min_note:
        min_note = Notes[i]
    if Notes[i] >= 10.0:
        nb_admis += 1

moy = somme / n
taux = (nb_admis / n) * 100

print("Moyenne :", round(moy, 2), "Max :", max_note, "Min :", min_note)
print("Taux de réussite :", round(taux, 1), "%")

1. Objectifs & Déroulement de la Séance

Savoirs (Connaissances)
  • Comprendre la portée (*scope*) : Variable locale (détruite après exécution) vs Variable globale (dans le programme principal).
  • Maîtriser les 2 modes de passage :
    • Passage par Valeur : Le module reçoit une copie (les types simples `int`, `float`, `str`, `bool` sont immuables).
    • Passage par Adresse : Transmet l'adresse mémoire (symbole @ en algorithmique, automatique en Python pour les objets mutables comme numpy.array et dict).
  • Connaître le rôle du mot-clé global en Python.
Savoir-faire (Compétences pratiques)
  • Identifier la portée de chaque variable et éviter les effets de bord indésirables.
  • Simuler le passage par adresse de plusieurs variables réelles en Python grâce aux retours multiples (return h, m, s).
  • 🚫 Règle Ministérielle Stricte : Si une variable globale est déclarée global dans un module, elle ne doit **jamais** figurer dans ses paramètres.

Synthèse du Cours

2. Portée des Variables & Modes de Transmission

L'exécution d'un module crée un espace mémoire isolé pour ses variables locales. La transmission d'information entre le programme principal et les modules dépend du mode de passage.

Diagramme Vectoriel : Passage par Valeur vs Passage par Adresse
Tableau Comparatif des Types & Modes de Passage en Python
Type de donnée Mode par Défaut En Algorithmique Comportement en Python
Types simples (int, float, str, bool) Par Valeur pf : Type Transmet une copie. Les modifications locales n'affectent pas la variable globale.
Types simples modifiés par adresse Par Adresse @pf : Type Simulé en Python par un retour de valeur (return val ou return h, m, s).
Tableaux 1D (numpy.array) & Dictionnaires Par Adresse @T : Tableau Transmet l'adresse mémoire (objet mutable). Les modifications du tableau affectent directement la structure d'origine.
Règle Ministérielle Stricte sur le Mot-Clé `global`

Si un module Python modifie directement une variable globale de type simple via l'instruction global ma_var, cette variable ne doit pas figurer dans la liste des paramètres de la fonction ou de la procédure.

Activité 1 : Prédiction d'Affichage & Piège du Passage par Valeur

Analyse de Script : Pourquoi `x` reste égal à 5 ?

Observez l'exécution du script suivant et expliquez pourquoi la variable x du programme principal ne change pas.

Script Python 
def modifier(x):
    x = x + 10
    print("Dans la fonction, x =", x)

# Programme principal
x = 5
modifier(x)
print("Dans le prog. principal, x =", x)
Résultat d'Exécution & Explication
Dans la fonction, x = 15
Dans le prog. principal, x = 5

Explication : L'argument x étant un entier (type simple `int`), il est transmis par valeur. La fonction modifier travaille sur une copie locale. L'affectation x = x + 10 modifie uniquement la copie locale, sans aucun effet sur le x du programme principal.

Activité 2 : Conversion de Temps & Permutation de Variables

Problème Pratique Modulaire

Énoncé du problème :

On souhaite concevoir une application modulaire qui :

  1. Saisit une durée totale exprimée en secondes (entier positif $> 0$).
  2. Utilise un module convertir_temps pour calculer le nombre d'heures, minutes et secondes réparties.
  3. Utilise un module permuter pour échanger les valeurs de deux entiers $A$ et $B$.
  4. Affiche les résultats de manière claire.

Algorithme Officiel (Conventions 2024-2025)
// Procédure de conversion
Procédure convertir_temps (sec_totales : Entier, @h : Entier, @m : Entier, @s : Entier)
LOCAUX
    reste : Entier
DEBUT
    h ← sec_totales Div 3600
    reste ← sec_totales Mod 3600
    m ← reste Div 60
    s ← reste Mod 60
FIN

// Procédure de permutation
Procédure permuter (@a : Entier, @b : Entier)
LOCAUX
    aux : Entier
DEBUT
    aux ← a
    a ← b
    b ← aux
FIN

ALGORITHME Conversion_Et_Permutation
DEBUT
    Répéter
        Écrire("Durée en secondes (>0) : ")
        Lire(duree)
    Jusqu'à (duree > 0)
    
    convertir_temps(duree, heures, minutes, secondes)
    Écrire(duree, " sec = ", heures, "h : ", minutes, "m : ", secondes, "s")
    
    Écrire("Donner A et B : ")
    Lire(v1, v2)

    Écrire("Après permutation : A = ", v1, " B = ", v2)
FIN
Implémentation Python (Thonny IDE)
# Module 1 : Conversion de secondes
def convertir_temps(sec_totales):
    h = sec_totales // 3600
    reste = sec_totales % 3600
    m = reste // 60
    s = reste % 60
    return h, m, s  # Retours multiples

# Module 2 : Permutation de deux variables
def permuter(a, b):
    aux = a
    a = b
    b = aux
    return a, b  # Simulation du passage par reference

# PROGRAMME PRINCIPAL
duree = int(input("Donner la durée en sec (> 0) : "))
while duree <= 0:
    duree = int(input("Invalide ! Donner sec > 0 : "))

heures, minutes, secondes = convertir_temps(duree)
print(duree, "sec =", heures, "h :", minutes, "min :", secondes, "s")

v1 = int(input("Donner A : "))
v2 = int(input("Donner B : "))

print("Avant permutation : A =", v1, ", B =", v2)
v1, v2 = permuter(v1, v2)  # Affectation multiple
print("Après permutation : A =", v1, ", B =", v2)

Comment indique-t-on le passage par adresse (ou référence) dans un en-tête d'algorithme ?
  • En précédant le paramètre du symbole '@' (ex: @x : Entier).
  • En écrivant le mot-clé 'ref' après le paramètre.
  • En mettant le paramètre entre crochets [x].

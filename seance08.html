Règle Ministérielle Stricte sur le Mot-Clé `global`

Si un module Python modifie directement une variable globale de type simple via l'instruction global ma_var, cette variable ne doit pas figurer dans la liste des paramètres de la fonction ou de la procédure.

Activité 1 : Prédiction d'Affichage & Piège du Passage par Valeur

Analyse de Script : Pourquoi `x` reste égal à 5 ?

Observez l'exécution du script suivant et expliquez pourquoi la variable x du programme principal ne change pas.

Script Python 
def modifier(x):
    x = x + 10
    print("Dans la fonction, x =", x)

# Programme principal
x = 5
modifier(x)
print("Dans le prog. principal, x =", x)
Résultat d'Exécution & Explication
Dans la fonction, x = 15
Dans le prog. principal, x = 5

Explication : L'argument x étant un entier (type simple `int`), il est transmis par valeur. La fonction modifier travaille sur une copie locale. L'affectation x = x + 10 modifie uniquement la copie locale, sans aucun effet sur le x du programme principal.

Activité 2 : Conversion de Temps & Permutation de Variables

Problème Pratique Modulaire

Énoncé du problème :

On souhaite concevoir une application modulaire qui :

  1. Saisit une durée totale exprimée en secondes (entier positif $> 0$).
  2. Utilise un module convertir_temps pour calculer le nombre d'heures, minutes et secondes réparties.
  3. Utilise un module permuter pour échanger les valeurs de deux entiers $A$ et $B$.
  4. Affiche les résultats de manière claire.

Implémentation Python (Python IDE)
# Module 1 : Conversion de secondes
def convertir_temps(sec_totales):
    h = sec_totales // 3600
    reste = sec_totales % 3600
    m = reste // 60
    s = reste % 60
    return h, m, s  # Retours multiples

# Module 2 : Permutation de deux variables
def permuter(a, b):
    aux = a
    a = b
    b = aux
    return a, b  # Simulation du passage par reference

# PROGRAMME PRINCIPAL
duree = int(input("Donner la durée en sec (> 0) : "))
while duree <= 0:
    duree = int(input("Invalide ! Donner sec > 0 : "))

heures, minutes, secondes = convertir_temps(duree)
print(duree, "sec =", heures, "h :", minutes, "min :", secondes, "s")

v1 = int(input("Donner A : "))
v2 = int(input("Donner B : "))

print("Avant permutation : A =", v1, ", B =", v2)
v1, v2 = permuter(v1, v2)  # Affectation multiple
print("Après permutation : A =", v1, ", B =", v2)

Évaluation Formative (Quiz Interactif)

1. Définition d'une variable locale ?
  • Une variable accessible uniquement dans le corps du sous-programme où elle est créée
  • Une variable accessible dans tout le programme
  • Une constante globale non modifiable
  • Une donnée enregistrée sur le disque
2. Paramètres formels vs paramètres effectifs ?
  • Effectifs dans la définition, formels à l'appel
  • Formels dans la définition, effectifs à l'appel
  • Mêmes variables
  • Effectifs toujours globaux
3. Correspondance entre paramètres effectifs et formels ?
  • Uniquement par le nom des variables
  • De manière totalement aléatoire
  • Par ordre de position, nombre et compatibilité de type
  • Par ordre alphabétique
4. Effet du passage par adresse (@) ?
  • Modifie la variable d'origine de l'appelant
  • Transmet une copie en lecture seule
  • Accélère le processeur
  • Rend la variable globale
5. Affectation dans une fonction sans le mot-clé global ?
  • Python crée une variable locale propre à cette fonction
  • Python modifie la variable globale du même nom
  • Python lève une NameError
  • Le programme s'arrête

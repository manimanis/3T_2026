Arithmétique II : Nombres Premiers & Décomposition en Facteurs

Test de primalité optimisé ($\le \sqrt{n}$), génération dans un tableau statique et décomposition canonique

OBJECTIFS D'APPRENTISSAGE

Théorème de la borne $\sqrt{n}$

Comprendre pourquoi si $n$ admet un diviseur non trivial, il admet obligatoirement au moins un diviseur $d \le \sqrt{n}$.

Arrêt immédiat

Interrompre immédiatement la boucle de test dès qu'un diviseur est détecté grâce à la boucle Tant Que.

Théorème fondamental de l'arithmétique

Tout entier $n \ge 2$ se décompose de manière unique en produit de facteurs premiers $p_1^{\alpha_1} \times p_2^{\alpha_2} \dots$

Patron officiel : Test de Primalité Optimisé

Pseudo-code algorithmique 
Fonction Est_Premier(n : Entier) : Booléen
Début
  Si (n < 2) Alors
    Retourner Faux
  Sinon
    d ← 2
    Tant Que (d * d <= n) Et (n Mod d ≠ 0) Faire
      d ← d + 1
    Fin Tant Que
    Retourner (d * d > n)
  Fin Si
Fin
Implémentation Python 
def est_premier(n: int) -> bool:
    if n < 2:
        return False
    d = 2
    while d * d <= n and n % d != 0:
        d += 1
    return d * d > n

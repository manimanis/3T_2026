Montage Électrique

Calcul de la Résistance $R$ & Câblage

Pour une LED rouge ($V_{\text{LED}} \approx 2.0\,\text{V}$, $I \approx 6\,\text{mA}$) sur le GPIO 4 ($3.3\,\text{V}$) :

$$R = \frac{V_{\text{GPIO}} - V_{\text{LED}}}{I} = \frac{3.3\,\text{V} - 2.0\,\text{V}}{0.006\,\text{A}} \approx 217\,\Omega \implies \mathbf{220\,\Omega}$$
  • Anode (+) : Broche GPIO 4.
  • Cathode (-) : Vers résistance $R = 220\,\Omega$.
  • Résistance : Vers la masse GND.

from machine import Pin
import time

led_in = Pin(2, Pin.OUT)
led_ext = Pin(4, Pin.OUT)

while True:
    led_in.value(1)
    led_ext.value(1)
    time.sleep(1)
    led_in.value(0)
    led_ext.value(0)
    time.sleep(1)
const int LED_IN = 2;
const int LED_EXT = 4;

void setup() {
  pinMode(LED_IN, OUTPUT);
  pinMode(LED_EXT, OUTPUT);
}

void loop() {
  digitalWrite(LED_IN, HIGH);
  digitalWrite(LED_EXT, HIGH);
  delay(1000);
  digitalWrite(LED_IN, LOW);
  digitalWrite(LED_EXT, LOW);
  delay(1000);
}

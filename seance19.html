2. Connexion au Réseau Wi-Fi en MicroPython

Le module `network` permet d'activer l'interface Wi-Fi de l'ESP32 en mode Station (`STA_IF`) :

import network
import time

wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect("Nom_Du_Reseau_WiFi", "MotDePasse")

while not wlan.isconnected():
    time.sleep(0.5)

print("✅ Connecté au Wi-Fi !")
print("📍 Adresse IP locale :", wlan.ifconfig()[0])

Serveur Web HTTP Embarqué & Sockets

1. Principe du Serveur Sockets HTTP

L'ESP32 écoute sur le port 80 les requêtes de type `GET /arrosage/on` envoyées par le navigateur du smartphone :

import usocket as socket

# Création de la socket TCP/IP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(('', 80)) # Port web 80
s.listen(5)

while True:
    conn, addr = s.accept()
    request = conn.recv(1024).decode('utf-8')
    
    if "/arrosage/on" in request:
        pompe.value(1) # Démarrer l'arrosage
    elif "/arrosage/off" in request:
        pompe.value(0) # Arrêter l'arrosage

    conn.close()

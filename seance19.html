Contexte & Fiche Pédagogique

Objectifs & Déroulement

Savoirs
  • Chaîne IoT complète : Capteurs → ESP32 → Wi-Fi → Actionneurs.
  • Serveur Web HTTP embarqué sur l'ESP32.
  • Module MicroPython network (mode Station STA_IF).
  • Sockets TCP/IP (usocket) sur le port 80.
Savoir-faire
  • Établir une connexion Wi-Fi en MicroPython.
  • Connecter capteurs (DHT11, LDR) et actionneurs (Servo, Pompe).
  • Générer la page HTML du tableau de bord embarqué.
  • Programmer une régulation automatique et une commande à distance.

Connexion Wi-Fi (MicroPython)

import network
import time

wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect("Mon_WiFi", "MotDePasse")

while not wlan.isconnected():
    time.sleep(0.5)

print("Connecté ! IP :", wlan.ifconfig()[0])

Serveur Web HTTP Embarqué

Écoute et Traitement des Requêtes HTTP (Port 80)

import usocket as socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(('', 80))
s.listen(5)

while True:
    conn, addr = s.accept()
    request = conn.recv(1024).decode('utf-8')
    
    if "/arrosage/on" in request:
        pompe.value(1)
    elif "/arrosage/off" in request:
        pompe.value(0)
        
    conn.send('HTTP/1.1 200 OK\nContent-Type: text/html\n\n' + html_page)
    conn.close()

Évaluation Formative

QCM d'Auto-évaluation

1. Mode Wi-Fi reliant l'ESP32 à un réseau existant :
  • Station (network.STA_IF)
  • Access Point (network.AP_IF)
  • Bluetooth Mesh
  • Ethernet Filaire
2. Port réseau standard du serveur Web HTTP :
  • Port 21
  • Port 80
  • Port 443
  • Port 8080
3. Principe d'une régulation en boucle fermée :
  • Pression manuelle chaque minute
  • Envoi d'un e-mail
  • Lecture capteur → test de seuil → commande automatique actionneur
  • Fonctionnement sans capteurs
4. Bibliothèque pour créer une Socket réseau HTTP en MicroPython :
  • socket (ou usocket)
  • network_http
  • web_express
  • requests_server
5. Réponse du serveur Web ESP32 à une requête HTTP GET :
  • Code HTTP 200 OK suivi de la page HTML du tableau de bord
  • Code MicroPython brut
  • Image binaire
  • Ordre d'extinction
